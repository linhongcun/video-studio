# EP.16 第二版视觉调度

2026-10-24，依据用户观看第一版后的直接反馈：信息持续密集，主要变化集中在字幕，动画没有承担讲解。第二版保留已经核验的旁白、示例、31句音频与4066帧时间，重做整个讲解舞台。

## 目标

每个阶段有一个明确焦点。对象按讲解需要进入、变化、退出；用余额变化、操作轨迹、共同确认和撤除过程解释内容。正文短语只帮助识别对象，避免把整段旁白再写一遍。

不把常驻两层大面板缩小后继续保留。未确认/已确认的技术区别，通过当前修改的大号状态、简洁原值锚点及确认时的落位过程逐步建立。

## 审查方法

先查看03、07至09、11的无字幕动态片段及连续帧，检查动作能否表达顺序与因果，再检查完整16镜。主体变化不能只来自标题/说明换字、淡入、背景或字幕。确认注意力、技术状态与节奏后再冻结源文件并整片渲染。
