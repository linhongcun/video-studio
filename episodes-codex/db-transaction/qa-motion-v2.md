# EP.16 第二版动画独立复核

2026-10-24（北京时间）。本轮针对用户观看第一版后的实际反馈：页面持续展示过多信息，变化主要发生在字幕，动画没有让观众看清正在发生的事。此报告检查动画是否承担解释功能，不把静帧美观或字幕同步等同于动画清楚。

## 验收标准

1. **当前焦点明确。** 入镜后能立即指出本镜主要看哪个余额、哪一步或哪种结果；尚未用到的信息延后引入，上一动作完成后不再需要的信息退出或退到低强调背景。
2. **动作有语义。** 扣款或入账的运算进入目标余额，数字/状态随动作改变；共同提交使两条修改一起确认；回滚使当前待确认修改撤销。单独淡入说明文字、装饰粒子、反复脉冲不能替代这些过程。
3. **渐进揭示。** 开头给冲突与最少必要对象；同库范围、两步、事务边界、待确认/已确认区别按讲解推进出现，不能首帧铺满整个模型。
4. **去掉字幕仍看得懂因果。** 检查无字幕关键片段及连续帧：能从对象运动、连接、数字变化和状态落点理解“谁发生了什么”，而不必读底部旁白才知道图在讲什么。
5. **留出读懂变化的时间。** 关键对象到位后有明确停留。焦点平移、大小变化和状态转换连接得上，不靠切换一整张无关信息卡推进。
6. **保留技术准确性。** 同一示例1000/500转200；待确认预览800/500或800/700不冒充已确认余额；提交后800/700；撤销后1000/500。应用主动回滚和提交前崩溃恢复分开，回滚不是让对方再转200回来。
7. **层次简洁。** 通常最多两个主要数据对象和一条短提示同时竞争注意力；角标与必要字幕保持次要。不能恢复“大标题＋转账栏＋两张大卡＋完整双层表＋步骤条＋长注释”的常驻布局。
