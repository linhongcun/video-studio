# TCC短片：动作与边界

单一资源示例，订单8124购买商品7042一件。正确基线可用4/本单预留0/正式售出0。三数量固定位置，颜色含义固定：蓝色可用、金色预留、青色正式售出；移动的一件从当前数量池退出，沿路径进入目标池，落点才提交新的计数，避免复制两个同一件。

成功路径是先预留，再按协调决定确认；失败路径明确重置后只释放本单预留。每次状态变化带操作号8124-库存；同一确认或释放重复到达时，查已保存结果后返回，数量不再变化。数量总和在每个稳定状态都为4。

首帧直接给出问题示例的错误直接售出，第二镜才引入TCC，第三镜回到正确初始状态。TCC挂词仅句首实测声学标签，顶部导航不用TCC抢跑。三个数量栏是具体业务数据，不是泛泛说明卡；各阶段焦点移动，当前以外栏退为上下文。

四类关键小样：预留4/0/0→3/1/0；确认3/1/0→3/0/1；释放3/1/0→4/0/0；重复确认/释放保持结果。先看无字幕连续过程，再加字幕检查配合与密度。确认和释放不可在一条未重置的时间线上顺次执行。
