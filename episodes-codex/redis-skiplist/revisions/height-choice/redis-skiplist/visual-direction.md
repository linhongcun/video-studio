# EP40 跳表动画方向

以一个55的插入任务贯穿10镜，不加入排行榜业务界面。先只显示底层有序链表，再显示40与70的额外上层链接；同一个逻辑节点的上下端口在同列并以竖线相连。只有一个当前游标和一条当下活动路径；比较候选不等于走过去，70过大时游标仍留40，在原节点下降。

所有实际forward边读取model.json相应snapshot，不以Scene.state声明代替实际绘制证据。节点位置由原8值加55的统一有序槽位固定，旧节点始终不重排；插入前55槽位为空，没有假成员。节点数字大、层间留空、链接端点止于节点边界，运动小标记不穿数字。

插入采用4条模型pointerWrites及各次snapshot：新55底层指60、50改指55；新55上层指70、40改指55。55出现后，仍存在的旧50到60边向下绕、旧40到70边向上绕，不穿过新节点框；它们直到对应前驱写入才消失。金色虚线是准备修改的边，不当作实际forward；抵达后按snapshot换成实线。单次写只改一个pointer，其他边保持。

首现术语按真实句首cue出现：链表、跳表、层高；课程标题不是术语讲解的替代。08/09写操作分准备、移动、抵达、停留，07先定位承接再说明层数，本例固定两层不假装随机抽样。所有动作窗口使用真实voice/SB包络，内部词语没有ASR精对齐。实际阅读时间待真实配音复验，不用加快语速压缩。

Canvas采用共享pageBg/pageInk。正文上方标题/章节，图形和状态在字幕带之上，底部无装饰进度。Cover16:9/4:3/3:4延续同一两层示例、单个路径与节点身份；4:3遵守x315..1125、y<918安全区。每份图由真实DOM审计与实看后封口，元数据textBoxes按实际字形回填；回填后仅用共享assemble同步SB.meta.covers，不改变语音时序。

QA入口Main props hideSubtitles/auditLayout，日志SKIPLIST_LAYOUT_AUDIT。实际DOM记录逻辑node、每层port/value/next、实际/待改边的路径及箭头、游标、移动点、比较文本、结果与字幕；独立检查从画出的边与文字反推可达性，而非信任insertion-progress或自述状态。预检须包括前进、不能前进、下降、每次写前后、上层淡入和新节点出现的中间态；当前说明不代表这些检查已经完成。
