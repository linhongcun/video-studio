# Redis 跳表视觉修订

本轮把现行Redis封面的冷银灰、Redis红和石墨文字用于正文及资料页。正文4557帧、资料150帧，共4707帧，1920×1080/30fps。两种层高、共同before重置、前向链接、节点/字幕位置与原分镜时序保持，完整基线AAC按包载荷、PTS/DTS/duration和解码PCM核对。

实际新入口：[`../height-choice/redis-skiplist/remotion/src/redis-style/index.ts`](../height-choice/redis-skiplist/remotion/src/redis-style/index.ts)。继续引用原模型、层高选项与分镜，旧入口和历史冻结不改写；`meta.sourcePath`保留实际Remotion目录，同目录README指向当前入口。

`source-sha256.json`绑定本轮实际输入与字体，`baseline-publication.json`保留替换前完整发布身份，`article.mdx`是当前发布稿原字节快照。`render-result.json`及资料回执记录最终媒体SHA和帧数；发布副本在`episodes/redis-skiplist/`。本地静音正文、带原AAC正文和最终视频是ignored编码产物，不作为已跟踪旧生产片改写。

从仓根执行共享[`redis-video/render.py`](../../../_shared/redis-video/render.py)，默认只打印计划；已有冻结只读核对，不重写追认。完整实际制作、成片和站点检查及发布状态见[`docs/archive/2026-10/redis-video-style/`](../../../../docs/archive/2026-10/redis-video-style/README.md)。历史来源日期保持，不声称本轮官网GET、ASR、全片人工听辨、真机或用户新观看认可。
