# 《AI说要调用工具，到底是谁在执行？》

A02 / EP.28，制作issue #132，制作及站点slug agent-tool-execution。2026-10-25（北京时间）开工，基线见README。

- 唯一问题：模型提出的工具调用请求，怎样变成应用程序真正执行的查询？结尾用执行记录与返回值回应。
- 前置：基本编程、接口与参数；可先看A01，但首屏独立交代本次查询目标。
- 第一帧是退款咨询功能界面：用户想查订单8124签收几天；助手准备查询，系统尚未收到。标明停在请求刚生成，不把正常交接阶段讲成故障。
- 11镜22句，一次有权查询贯穿请求→应用检查→实际HTTP→结果→答复；再明确重置为新用户新会话，展示权限拒绝0次HTTP。正文不讲MCP、完整循环、退款规则或写操作。
- 数据全为教学合成：订单8124，已签收3天。demo实际运行本地只读HTTP接口，模型输出使用固定fixture；没有调用真实模型、真实订单服务或退款操作。教学动画不冒充服务录像。
- 正式术语按真实句首起音引入：02模型、03工具调用请求、04应用程序；工具名/参数仅03一处代码，调用标识用视觉关联，不连续堆JSON。
- 02回看开始、08重置失败情景、11收回总结均有口头衔接。应用内程序与模型分工明确；托管工具的运行时差异放文章，片尾限定本应用。
- 旁白按独立叙事审读后的最小修订定稿；后续如需改词，先停相关配音与编码，重新建立哈希。
- 官方资料及实际示例证据见research.md、demo/README.md及demo/verified-results.json。
