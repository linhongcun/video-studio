# EP.04 制作说明

## 讲什么

同一个网站、同一个账户，逐步演示服务器会话、浏览器 Cookie 与有效性检查。 短片只保留一条主线，文章补边界。详细逐镜动作见 visual-direction.md，内容依据见 research.md。

## 画面与动作

1920×1080、30fps。正片以 Remotion 生成，以同一组对象持续承接请求/响应/状态变化。浏览器壳只承载真实教学网页；解释的表、记录与网络节点使用全屏画布，不画实物设备或假应用窗。深色页身 #0F172A，正文 #E5E7EB。标题在主体动作之上，字幕单层在 y920..1045，主要内容底边小于900。

请求和数据沿路径移动，服务器/缓存状态在动作落点后改变。非当前信息退出或降为上下文；不以字幕变化充当动画。画面上的账户、编号和网络路径都是教学示例，不引用无来源的性能数值。

## 配音与时序

共享 prep.py → gen.py → build.py 铺轨；assemble.py 只把整轨与句级时间连接到字幕/分镜，import 唯一共享 Rule，不复制算法。配音总长 3344帧，111.467秒。words.json 和 storyboard.json 按实际SHA冻结。整轨0帧放置，place_v2.py 校验后复制实体音频；标签只按句首声学起音显示。

## 封面

本期 Cover.tsx 与 covers.json 一致，生成16:9、4:3、3:4。4:3全部主要文字在 x315..1125、y<918；水印与内容区域分开。字幕保持原旁白逐字，不使用TTS替换文本。

## 验证范围

严格起音、整轨放置、字幕与旁白一致、实际编码帧数/分辨率/音量、输入哈希、关键连续动作与多阶段画面分开检查。没有逐字ASR或人工听辨时明确记录，不能伪称已完成。发布由root统一接入站点并核验线上完整SHA。

主动退出分支：11镜另起示例，标题明确“另一种情况：从有效会话退出”。10镜过期案例不会自行恢复；11镜单独从有效状态演示主动退出，身份仍用同一教学编号以便比较，但有明确的分支重置提示。

总结镜：12镜标题明确标“回顾”，以静音观看也能识别这是有效会话工作方式的概括，不把11镜退出状态当成自动恢复。旧主体/结果/Flow统一退出，再让品牌进入。
