# 读音与送模说明

以下为正常口播读法，不改变script中的文字；本轮仅生成01–03六句，04–13复用原镜03–12的20句，原take文本与实际SHA须保留。仅在实际TTS听辨或量值复核发现问题时记录替换，不把未做的逐字识别写成通过。

| 文本 | 读法 | 镜号 |
|---|---|---|
| 二维数组 | èr wéi shù zǔ | 01 |

| 列 | liè | 01、02、12 |
| 行零、列一 | 行下标0、列下标1，分开读清，不按第一个位置理解 | 02 |
