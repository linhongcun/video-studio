# 读音与送模说明

以下是正常口播读法，不改变script中的文字。仅在实际TTS听辨或量值复核发现问题时，在送模记录中精确说明替换，不把未做的逐字识别写成通过。

| 文本 | 读法 | 镜号 |
|---|---|---|
| A、B、C、D、E、F | 分别按英文字母读 /eɪ/、/biː/、/siː/、/diː/、/iː/、/ɛf/，每个标签对应一座城市 | 02、07–10 |
| 省份 | shěng fèn | 01、06、12 |
| 数一共 | shǔ yí gòng | 01 |
| 组数 | zǔ shù | 04、07–10 |
| 行和列 | háng hé liè | 11 |
| 处理 | chǔ lǐ | 04、07、11、12 |
| 相连 | xiāng lián | 01、02、03、07、08、10、11 |
| 一组、两组、三组 | zǔ | 02–04、06–09 |
| 代表 | dài biǎo | 04、05、07、08、09 |
| 记录 | jì lù | 05、07 |
| 根 | gēn | 05、06、07–10 |
| 并查集 | bìng chá jí | 06 |
| 只检查 | zhǐ jiǎn chá | 10 |
| 对称 | duì chèn | 11 |
| 对角线 | duì jiǎo xiàn | 11 |
| 按大小 | àn dà xiǎo | 12 |
| 缩短 | suō duǎn | 12 |
| 线性 | xiàn xìng | 12 |
| Python | 按技术名称一个单词读，不拆字母 | 12 |

α(n)、parent、find、isConnected、下标0–5只在屏幕/代码出现，不要求口播公式或逐字母念变量。A–F是城市标签，屏幕一直可核对它们依次对应0–5。
