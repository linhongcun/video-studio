# 岛屿数量：怎样保证一座岛只数一次？

海面上看见七块陆地，不代表有七座岛。关键是先把相连的整片陆地认出来，再去寻找下一座。

## 先看海陆地图要数什么 {#problem}

LeetCode 200给出一个非空的`m × n`字符网格：`"1"`表示陆地，`"0"`表示海水。上下左右相邻的陆地可以连接成同一座岛，只有斜角接触不相连。要求返回岛屿的座数这个整数。[1][2]

<SourceQuote sourceId="A1" supports="岛屿通过上下或左右相邻的陆地连接，斜角接触不连通。" translation="岛屿被水包围，由水平或垂直相邻的陆地连接而成。可以假设网格四条边都被水包围。" />

题目中`1 ≤ m,n ≤ 300`，每格只可能是字符`"0"`或`"1"`。网格外面视为水，边缘格本身也可以是陆地；不需要额外一圈全零边框。[1][2]

视频始终使用官方第二个例子：

```text
11000
11000
00100
00011
```

地图有4行5列、7块陆地。左上四块通过共享边缘连成一座，第三行第三列是独立的一座，第四行右侧两块组成第三座，所以返回`3`。中央那一块与另外两座之间只有斜角接近，没有可通过的四邻陆地连接。

视频地图与中文说明的行列从1开始；Python和下面的程序坐标从0开始。例如地图“第一行第二列”对应`grid[0][1]`。后文表格继续使用视频的1起行列，避免在同一过程里混换称呼。


首格在第一行第一列，也要检查四个方向：向右、向下可能找到陆地，向左、向上则已越出地图。先判断坐标是否在范围内，越界就直接跳过，不读取格值、不标记，也不入栈；这并不表示搜索只向右、向下。

## 先想怎样避免重复 {#derive}

如果每看到一块陆地就给答案加一，左上同一座岛会被算四遍。要数整座岛，需要保存已经归属于某座岛的陆地：扫描到新陆地时加一，然后把与它四邻相连的整片陆地都找出来、登记归属。之后再扫描到这片岛的其他位置，就能直接跳过。

从一个位置出发，沿相邻陆地向前找；遇到分岔时，先记住还没有继续检查的分支，沿当前分支继续，随后再回来。这个选择过程对应**深度优先搜索（DFS）**。用一个**栈**保存待展开位置，最后放入的位置先取出，便可以完成这种搜索。Python列表的`append()`向末端添加元素，无下标的`pop()`取出末端元素，恰好支持后进先出。[3]

本片用`seen`集合保存已经归属的坐标。[4] 一块陆地一经发现，就先登记进`seen`，随后放进栈。它还可能留在栈里等待检查，因此“已经归属”和“已经展开完”是两个状态；原地图中的陆地和海水始终不变。

采用显式栈也使程序不依赖递归调用的深度。本题最多有90000格，细长岛屿上的搜索路线可能很深；Python解释器有递归深度限制，提高限制的安全范围依平台而定。[5] 下面的迭代程序直接维护待处理位置。

## 沿四邻找完一座再继续 {#search}

正式开始时，归属集合与栈都为空，岛数为零。外层按行从左到右扫描每一格：水格跳过，已经归属的陆地也跳过；只有遇到未归属的陆地，才发现一座新岛。

先从第一行第一列开始，岛数变成一，把它标记后放入栈。程序检查邻居的顺序固定为**右、下、左、上**；因为栈后进先出，后放进去的下面一格先展开。

| 阶段 | 当前检查的位置 | 栈中的待展开位置，左为底、右为顶 | 归属情况 |
| --- | --- | --- | --- |
| 找到首岛起点 | 尚未展开 | `(1行,1列)` | 起点已归属 |
| 起点检查完四邻 | `(1行,1列)` | `(1行,2列)`、`(2行,1列)` | 先发现右邻，再发现下邻 |
| 取出下邻，发现它右边的陆地 | `(2行,1列)` | `(1行,2列)`、`(2行,2列)` | 左上四块都已归属 |
| 取出右下格，检查其上邻 | `(2行,2列)` | `(1行,2列)` | 上邻已归属，跳过，不再入栈 |
| 最后取出并检查完右上格 | `(1行,2列)` | 空 | 首岛的四块都展开完了 |

中间最容易混淆的一步是：第二行第二列向上看见第一行第二列时，后者仍在栈里，尚未展开。因为它早已登记归属，所以不会重复加入；之后仍会从原来的栈项取出并检查它的四邻。

首岛栈空后，外层继续原来的逐行扫描。前面已归属的陆地直接跳过，到第三行第三列才发现第二座岛，答案加到二。它的四个邻格都是水，第四行第四列只在斜角方向，不能加入。

继续扫描到第四行第四列，发现第三座岛，答案加到三。展开它时，向右找到第四行第五列；两块陆地归为同一座。它们都处理完，再扫描到已经归属的最后一格并跳过，整张地图结束，返回`3`。

### 为什么能找全，而且每座只数一次

从起点出发，搜索只加入相邻陆地，所以加入的每一格都属于同一座岛。假设栈空后还有同岛陆地未归属：取一条从起点通往它的四邻陆地路径，路径上必有第一条从已归属格通向未归属格的边。已归属格最终会被取出检查四邻，因此必然会发现那一格，和“仍未归属”矛盾。由此，栈空时恰好找完这座岛。

外层每次加一，都从尚未归属的陆地开始；已经计数过的岛，其全部陆地都在`seen`里，不会再次触发新起点。每座岛又总有第一块被扫描到的陆地，所以每座都恰好触发一次加一。

先登记、再入栈，还保证一块陆地即使从不同方向被遇见，也只有第一次能够入栈。它不会在等待展开时被反复加入，整个过程最终会结束。

## 把归属规则写进程序 {#code}

实现里有两层工作：外层扫描找新岛，内层循环展开这一座岛。`islands += 1`只出现在外层的新岛分支；内层发现同岛邻居时，只登记、入栈，不增加岛数。

下面是视频末卡使用的同源完整Python程序。它接收题目规定的非空字符网格，保留输入，使用内置`set`与`list`，可直接按LeetCode接口提交。

```python
class Solution:
    def numIslands(self, grid: list[list[str]]) -> int:
        rows, cols = len(grid), len(grid[0])
        seen = set()
        islands = 0
        directions = [(0, 1), (1, 0), (0, -1), (-1, 0)]

        for row in range(rows):
            for col in range(cols):
                if grid[row][col] == "0" or (row, col) in seen:
                    continue
                islands += 1
                seen.add((row, col))
                stack = [(row, col)]
                while stack:
                    r, c = stack.pop()
                    for dr, dc in directions:
                        nr, nc = r + dr, c + dc
                        if not (0 <= nr < rows and 0 <= nc < cols):
                            continue
                        if grid[nr][nc] == "0" or (nr, nc) in seen:
                            continue
                        seen.add((nr, nc))
                        stack.append((nr, nc))

        return islands
```

两处登记都在对应入栈之前：新岛的起点先加入`seen`再建立栈；新发现的邻居先`seen.add((nr, nc))`再`stack.append((nr, nc))`。越界位置、水格与已归属位置都不会入栈。

外层检查`m × n`格一次，每块陆地最多入栈、出栈一次，展开时检查四个方向。按集合插入与成员查询期望常数时间的通常模型，时间复杂度为`O(mn)`。归属集合和待展开栈最多保存`O(mn)`个坐标，额外空间为`O(mn)`。

几个边界可以直接用同一规则理解：全是水时返回`0`；只有一块陆地时返回`1`；两块陆地仅斜角相邻时返回`2`。行数为一、列数为一或陆地位于边缘时，程序仍通过边界判断限制四邻访问。
