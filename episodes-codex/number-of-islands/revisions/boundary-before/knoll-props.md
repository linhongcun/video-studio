# LC200 制作合同 · 找完整座再继续

依据script.md、plan.json、episode-config.json、covers.json、solution.py与research/demo-trace.json。新片14镜28句、四章，仅片内LeetCode200；内部EP34用于制作排序。真实声轨、句长、分镜和哈希未由此文生成，绝对时序以root实际装配冻结为准。

主体是题目原生海陆地图；4×5地形11000/11000/00100/00011、7陆格、3岛。海岸/陆地不改；四邻共享边缘决定相连，斜角留海水间隙。中文画面/旁白坐标1起，代码/trace0起在13作显式映射。seen表示已归属，不表示已经展开，栈只存待展开，当前检查单独标注。

| 镜 | visualType | 主要因果状态 |
| --- | --- | --- |
| 01 | problem | 给你一张地图，一代表陆地，零代表海水，上下左右连成的一片陆地算一座岛。题目要数出岛屿的数量，返回一个整数。 |
| 02 | example | 这张四行五列的地图里，有七块陆地，却只有三座岛。左上四块连成一座，单独的一块和右下两块各成一座，斜角相碰不算相连。 |
| 03 | derive-component | 如果每发现一块陆地就加一，左上同一座岛就会被算四遍。我们需要先认出整座岛并留下标记，再去找还没归属的陆地。 |
| 04 | derive-search | 从一块新陆地出发，只沿上下左右找相邻陆地，有分岔就记住还没继续看的位置。深度优先搜索，也叫DFS，就是先沿一条分支继续找，再回来处理留下的分支。 |
| 05 | seed | 现在清空演示标记，从原地图第一行第一列开始，逐行寻找新岛。发现第一块未归属的陆地，岛数加一，先把它标为已归属。 |
| 06 | stack-rule | 栈把待展开的位置按后放先看的顺序保存，标记只表示已经归属，不代表已经看完周围。先放入右边的第一行第二列，再放入下面的第二行第一列。 |
| 07 | take-down | 后放入的下面这一块先取出，接着发现它右边第二行第二列的陆地。先标记再放进待处理的位置，第一行第二列还留着，稍后才展开。 |
| 08 | skip-seen | 来到第二行第二列，向上又遇见第一行第二列，但它早有归属，不再放入。最后回头处理那块待展开的陆地，栈空了，第一座岛才找完。 |
| 09 | resume-scan | 回到逐行扫描，第一座岛的其余陆地都已有标记，直接跳过。直到第三行第三列出现新陆地，岛数才从一变成二。 |
| 10 | water-boundary | 这块陆地的上下左右都是海水，向四周都走不通。虽然第四行第四列就在斜角方向，也不能把它算进这座岛。 |
| 11 | third-island | 继续扫描到第四行第四列，再把岛数加到三，向右找到最后一块相连陆地。两块陆地归为同一座，地图也扫描完了，返回三。 |
| 12 | complexity | 每块陆地最多放入和取出一次，每次只检查四个方向，所以时间随地图格数增长。标记和待处理位置最多保存整张地图的陆地，因此额外空间也和格数同阶。 |
| 13 | implementation | 写成程序，先标记已归属，再把位置放进栈，才能避免从不同方向重复加入。岛数只在外层扫描遇到新岛时加一，展开邻居时不增加。 |
| 14 | closing | 这七块陆地最终分成三座岛，关键是每次先把同一座完整找出来。地形始终没改，变的只是归属标记和待处理位置，完整Python程序可以暂停查看。 |
