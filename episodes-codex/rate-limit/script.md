# EP.11《抢票时，为什么总提示系统繁忙？》

2026-10-24 Codex重制。单一入口、两个抽象额度格贯穿全片；示例设置容量2、每秒补1，只解释算法，不冒充真实服务承载能力。

- 只讲限流与令牌桶两个术语；标签在独立句首实测起音出现并完整停留至少63帧。
- 没有实物桶、门、票据比喻，没有假应用窗口；全屏深色canvas直接展示请求与抽象计数。
- 通过入口不代表业务成功，不声称所有繁忙提示都是限流，也不保证按到达顺序或公平。
- 动画必须画出扣额在前、放行在后；无额度拒绝，不偷偷排队；补额按时间发生，不随点击加快。
- Envoy官方令牌桶实现与MDN 429正文实读记录见research.md；无逐字ASR时如实说明。
