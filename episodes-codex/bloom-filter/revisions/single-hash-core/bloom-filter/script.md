# 布隆过滤器：为什么能确定不存在，却只能说可能存在？

EP39修订；工程算法第二期。主线采用单位置最简Bloom，复用公开URL与首发身份。

- 唯一问题：压缩的0/1标记，为什么能确定未加入，却只能说可能存在？
- 直接使用元素A/B/C/D与8格数组；主线一次哈希，无商品、查库或业务同步支线。
- A/B写3，D查7得0，C查3得1却未加入；错误清位说明共享边界。
- 片尾仅一个两位置对照，必须先用同一A/B完整重建，再查C的3/5；只解释本次排除，不报告误判率或宣称每个查询都改善。
- 固定SHA派生位置为可复算教学规则，不是Redis/Guava内部实现。
- 9镜18句；术语：位数组、哈希、布隆过滤器。实际时长服从配音与动作，不加速。
- 默认附录为原始题名及连续原文短引，一页5秒。

### 01 goal

frame：canvas
画面：第一帧显示元素A与8个全0格，元素是判断对象，格子是压缩标记，不画商品、数据库或业务流程。问题落在是否加入，不提前输出最终两分支。
旁白：想判断一个元素有没有被加入过，我们可以先用一小排零和一，留下标记。可这些格子并不保存元素本身，究竟能判断得多准确？
屏幕文字：元素有没有加入过？；只留下0和1。
出处：research.md、references.json及model.json；元素与位值为可复算教学示例。

### 02 bits

frame：canvas
画面：8个等大格子初始全0，编号0–7在格外，值在格内；先突出值，再突出外部编号，术语按第二句真实起音出现。
旁白：先准备八个格子，每格只能放零或一，开始全部是零。位数组就是这一排标记；外面的零到七是位置编号，格子里面才是保存的值。
屏幕文字：8个格子，初始全0；外面：位置编号；里面：0或1。
出处：research.md、references.json及model.json；元素与位值为可复算教学示例。

### 03 insert-a

frame：canvas
画面：保持原空数组；A经一个哈希计算框到3，单箭头抵达后3从0变1，其他格不变；明确一次计算为教学最简版，不能画三分叉。
旁白：哈希按固定规则把元素算成位置，同一个元素每次都到同一格。先用最简单的一次计算：加入元素A，算到三号位，就把这里从零改成一。
屏幕文字：A → 哈希 → 3；加入：0变1；同一输入，位置不变。
出处：research.md、references.json及model.json；元素与位值为可复算教学示例。

### 04 insert-b

frame：canvas
画面：在A已写入状态上B经同一个计算框到3；3保持1而不是2。短暂回显A/B共享3的解释线，清楚标为解释，并撤去，不伪装为真实保存的所有权。
旁白：再加入元素B，它也算到三号位，这就发生了碰撞；已经是一，就仍然保留一。布隆过滤器让不同元素共享这些标记，格子里既没有元素内容，也没有记录是谁写过。
屏幕文字：B → 3；碰撞：1仍为1；只存标记，不存元素。
出处：research.md、references.json及model.json；元素与位值为可复算教学示例。

### 05 query-zero

frame：canvas
画面：数组只有3为1。D计算到7，读0，输出确定未加入。回扣插入必置1的逻辑，不画产品或查库链路，不误清3。
旁白：写入看清了，再看查询：用相同规则计算元素D，落在七号位，这里还是零。若D真被加入过，七号位当时就会变成一；所以标记正确保留时，这个零足以确定它没被加入。
屏幕文字：D → 7 → 0；确定未加入；前提：正确加入并保留标记。
出处：research.md、references.json及model.json；元素与位值为可复算教学示例。

### 06 query-one

frame：canvas
画面：C从未有插入动作，查询C到3读1，先输出可能存在，再明确C实际未加入；回显A/B留下标记的因果，不能把真实成员标签画成位数组存储内容。
旁白：再查从没加入的元素C，它也落在三号位，却读到了一。这个一是A和B留下的，不能证明C加入过；所以读到一，只能说可能存在。
屏幕文字：C → 3 → 1；可能存在；C未加入：这次误判。
出处：research.md、references.json及model.json；元素与位值为可复算教学示例。

### 07 unsafe-delete

frame：canvas
画面：明确进入错误操作反例，真实成员A被移除B仍在；3由1清0，B到3读0显示错误排除。该反例结束撤销错误清位，不能描绘成受支持删除。
旁白：共享也带来一个限制：普通布隆过滤器不能靠直接清零，来删除元素。若删除A时清掉三号位，仍在集合里的B再来查询，就会被错误排除。
屏幕文字：错误操作：删除A时清零3；B仍在，却被错排除。
出处：research.md、references.json及model.json；元素与位值为可复算教学示例。

### 08 extra-position

frame：canvas
画面：明确另一份重建对照，不把旧单位置数组直接按新规则查询。新数组先空，A依次写3/2，B依次写3/1，完成后仅1/2/3为1，再C检查3/5读1/0而排除。分阶段揭示，不常驻双路扇出。
旁白：一次计算已经能讲清原理；为减少误判，实际也常让每个元素对应多个位置。另建一份两位置的数组，把A和B都重新加入；这次C要检查三号和五号，五号为零，便排除了刚才那次误判。
屏幕文字：另建两位置对照；先重新加入A和B；C：3是1，5是0 → 排除本次误判。
出处：research.md、references.json及model.json；元素与位值为可复算教学示例。

### 09 tradeoff

frame：canvas
画面：撤去两位置对照，回到单位置正常示例3为1；同一数组分别回顾D7读0/C3读1。取舍用简短三项字词，收束回原问题，不追加业务和维护支线。
旁白：位置也不是越多越好，因为写入的标记更多，数组也会更拥挤，要和空间、预计元素数量一起选择。记住核心：正确加入并保留标记时，碰到零可以排除，全是一也只代表可能存在。
屏幕文字：空间、预计数量、位置次数一起选择；0：可排除；全1：仅可能存在。
出处：research.md、references.json及model.json；元素与位值为可复算教学示例。
