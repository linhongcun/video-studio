# 布隆过滤器制作说明

- Main从本期storyboard读取真实镜长、字幕、句首cue与voice区间；模型数据仅来自model.json。
- 稳定对象：16位数组的位置不移动；商品101/205/001/067采用三位显示，数组下标不带商品前缀。
- 写入顺序遵从三路输出；抵达后0→1，重复写1保持1。每步有独立移动和停留，不用同时亮一整排代替操作。
- 查询001在位置12读1、位置2读0后停止；067读14/0/15全1后只产出可能存在，真实目录负责确认。
- 反例必须带标签：capacity另示意；错误删除结束恢复位图及目录；目录新增001仅发生在maintenance。
- Main支持hideSubtitles用于无字幕过程复核，auditLayout输出BLOOM_LAYOUT_AUDIT及可机读位值/目录状态。审计只测实际布局，不评价教学效果。
- 封面三比例及原题参考资料附录按最新共享流程执行。此说明不宣称真实音轨预演、正式媒体或发布检查已完成。
