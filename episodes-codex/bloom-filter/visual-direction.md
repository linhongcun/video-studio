# 布隆过滤器画面方向

主体采用深色全屏canvas，初始商品查询功能为教学示意；进入内部机制后撤去产品界面，不给位数组或流程加浏览器外壳。位数组始终使用下方同一排16格，左至右位置0—15，格内是0/1标记，格外是位置编号。商品编号保留三位显示，和数组下标分别标识。

输入在左上；三路固定计算输出占据三个固定位置槽。活动路径逐个从输出槽抵达对应格子，抵达时才写1或读出该位；位值不滚动叠字。共享3号位保持1，不计数。查询001只实际探测12和2，看到2为0便停止，位置15仍未探测。查询067读14/0/15全1后，才放行真实目录查询；其业务结果仍是未收录。

标记来源只在shared-marks镜作为讲解覆盖层出现，完成后撤去；归属由model.items实际positions推得，真实格子从不保存来源标识。capacity镜明确为另一份容量示意，末尾恢复原位图，不把自造置位动画当作本期哈希的实际结果。bad-delete镜显示红色错误操作标识，结束同时恢复位图和目录；maintenance镜才让目录新增001，先显示旧标记不安全，再用相同三个位置更新标记。错误反例不作为普通查询的正常历史。

文字安全区域为x75—1845、y42—955。标题/副标题、计算槽、位数组、判断/目录分别占据独立垂直区域；原生字幕位于更低区域。正式动画均由实际storyboard的选中句级voice包络驱动，不使用CSS或墙钟动画。运动窗口仍需在真实配音到位后实际预演、采样中间态和复核停留时间，当前实现不代表已验收。

封面使用同一模型表达确定排除与可能存在，不放虚构性能数字。三比例独立构图，4:3主体位于x315—1125且y<918；水印按对应zone。实际DOM文字边界审计与人工看图结果另行记录。
