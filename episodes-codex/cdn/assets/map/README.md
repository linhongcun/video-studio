# 地图数据与投影

实际读取日期2026-10-24。Natural Earth上游README明确其地图数据为public domain并可免费用于任何项目，保留原文source/upstream-README.md作为许可依据；上游没有LICENSE文件（请求返回404），不编造许可证。此处只使用110m land大陆轮廓，不含行政边界。固定上游commit、URL、原始GeoJSON完整SHA及字节数见source/metadata.json。

convert.py连续解包每个经度环，制作±360度副本，以确定性的等距经纬投影转换为remotion/src/landPaths.ts；按太平洋区域窗口裁切，不是手绘大陆或示意世界地图。投影每度7.5px，longitude55..255、latitude−5..75，对应主画面x210..1710、y290..890。SVG窗口为了版式略向两侧延展；实际经纬投影仍保持等比例。

教学点位：用户(113E,24N)，选中边缘(132E,35N)，远端源站(125W,38N)；其他点位仅表示存在其他节点，不对应厂商真实部署。网络路径是角色间的示例曲线，不是物理光缆、真实跳数或地理最近保证。运行时只读取本地src路径，没有远程URL。

请求在标记点之间走蓝色路径，返回图片在同一角色的图片锚点之间走绿色路径。路径层在节点/图片主体下方；移动图片与静态落点同为128px，避免落点尺寸跳变。副本只在选中节点按规则落下，其他点始终未检查。
