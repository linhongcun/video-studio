# EP.17 制作说明

当前制作入口remotion/src/Main.tsx，主线为同一条商品7042记录、库存1与甲乙两请求。数据流以可追踪路径移动；甲用金色、乙用蓝色，确认用青色，旧值误用与缺货用红色。颜色有固定含义，不能只作为装饰。

前六镜普通读与绝对写回展示错误流程。第四、五镜分别移动焦点和主要对象，其他请求缩退为上下文；不是单靠字幕换页。第七镜明示重置为新例，原值恢复1。第八镜行锁标签按起音出现，代码只此一处；甲先获得锁不承诺到达次序公平。第九镜乙请求停在记录之外，不显示任何库存读取结果。第十镜本次修改0在提交前为金色，并保留原确认1；提交后0为青色，释放标记撤除。第十一镜同位置0流回乙，之后才判断；第十二镜缺货且不再扣减，乙结束事务。最后复盘按步骤出现，旧内容退出后才引入昵称预告。

页身颜色来自共享pageTheme，1920×1080、30fps。字幕区域x130..1790、y925..1035，正文与代码均在其上；固定品牌右上角。封面三尺寸分别布局，4:3核心区x315..1125，底部声明止于918上方。

配音共享MiMo冰糖，TTS、裁切、铺轨、起音和混音均复用episodes/_shared。句级包络不冒充ASR逐字对齐；两个术语都在独立句首。标签持续至少63帧。实际镜长由音轨决定，不追加全局片尾。
