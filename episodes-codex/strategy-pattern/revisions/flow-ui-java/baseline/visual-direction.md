# 策略模式：语言无关的设计关系

2026-10-25。当前11镜22句，以结算流程、定价策略、选择三类职责解释变化隔离和协作。视频无源代码、函数、参数、语言标识、整数分换算或类图；具体实现只在图文可选附录。

## 稳定布局

结算保留“读取原价→使用当前定价策略→显示应付”的共同流程。选择标记在流程外侧，决定本次采用谁。下方固定区域只展开当前策略，另一种只留名称。原价100元为蓝色，策略名称为青色，结果90/80元为金色，均有文字身份，不能只靠颜色。

流程图的阶段与当前点仅随业务行动推进，解释谁做什么；不得变成按片长持续增长的装饰进度条。主体干净深色canvas，无比喻、实物或无关应用外壳。

## 每段必须表现的思想

01–02：同一任务不同定价做法；共同步骤与变化细节混放，使维护一种规则要进入共同流程，不宣称两条简单判断天然错误。
03–04：先将两种定价办法各自独立，再命名策略模式；04首句声学起音显示术语至少63帧。共同约定为同一订单的原金额到其应付金额，业务含义相同、具体算法和结果可不同。
05–06：外侧选择会员，然后流程读100元，走到定价时交给会员策略；策略按九折计算并交回90元，结算才使用结果继续。选择、具体计算和流程协作分别有归属。
07：清旧90元、重置原价100元、外侧选择活动，再走同样流程得到80元；会员不执行，不叠优惠。完整动作有可读停留。
08：突出稳定流程依赖共同约定，九折/八折细节仍在各自策略内；不能只演两个结果，必须指出流程为何按同一种方式工作。
09：在共同约定不变、本例策略内部变化的前提下说明维护边界，不再增加新折扣数值，不承诺结算永久不改。
10–11：选择和协作仍需维护、阅读多一层追踪；稳定少量规则可以直接处理。最后按已有三类职责回收思想，不讲实现写法。
