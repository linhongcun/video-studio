当前静态示意保留原片底层10/20/30/40/50/60/70/80与上层40/70，查55先到上层40，70过大则在40下降，再到底层50，60过大则停；目标仍在50与60之间。活动路径不进入70或60，55没有接入图。它是前向链接教学示例，不能当作小集合默认Redis内存、真实运行截图或性能测试。封面不重制正文、不改变范围或首发身份。

背景图由图像生成工具制作，只含无文字、无技术事实的静态边角装饰；真实文字与链接图由确定SVG生成。Redis原标记按原字节复用[middleware-identity](../middleware-identity/NOTICE.md)，来源、MIT许可及商标边界随完整输入SHA记录，不表示官方授权或背书。style-v1为固定配色/字体契约；后续题库只扩catalog和图义，不因新增单集改写旧输入。

尺寸：1920×1080、1080×1440、1440×1080。横版左文右图，竖版上文下图；4:3将完整竖版以0.75倍居中在x315..1125，重要内容底边y<918。实际字体、重要图形、边框和组间距均检查；安全边界不保证每种原生播放器控件状态无遮挡。

