# LC.739 每日温度：还要等几天，才会更暖？

唯一承诺：给每一天找到未来第一个严格更暖的日子，并把等待天数写回原来的那一天。

画面约定：干净深色canvas；使用连续天序的气温线、逐日温度高度与当天位置演出原题；辅助待解决区始终连回原来的天；无浏览器壳、无无关实物、无装饰进度条。画面显示“第1天”到“第8天”，程序下标从0开始，两个位置之差不变。33–36等温度为满足官方30..100约束的自选教学示例，不声称真实天气预报；不补摄氏或华氏单位。图形从28这一基准起画，并明确标示，避免暗示绝对零点。

来源：2026-10-25实际读取[官方中文题面](https://leetcode.cn/problems/daily-temperatures/description/)及[官方英文题面](https://leetcode.com/problems/daily-temperatures/description/)，访问证据见research/source-access.json。方法、证明与自选样例为本期推导，执行源为solution.py，动画只读真实执行trace。

时序状态：阶段1全部为provisionalTiming/pendingAudio；每镜恰好2整句，正常语速目标约2–2.5分钟；未生成配音，不把占位帧称为起音检查通过。片尾另留150帧静态完整Python，字幕与旁白在卡前结束。

## 第二章 为什么这样保存

### 03 repeat
frame：canvas
画面：先从第3天向右查看较冷的几天，再从第4天重复查看第5、6天；旧查找轨迹淡出，留下第3、4、5天的待解决标记。
旁白：接着想怎么找：每天都向后查，会反复查看相同的日子。不如按日期前进，把没等到答案的天留下。
屏幕文字：重复向后找 → 保留未解决的天

### 04 order
frame：canvas
画面：保持第3天35、第4天31、第5天30原位；辅助区从左到右对应35、31、30，连线仍指回日期；第6天32首先对比最近的30，再对比31，遇35停止。
旁白：新来一天，比最近留下的天更暖，就先解决它。如果还不够暖，更早留下的温度不会更低，也不能解决。
屏幕文字：从最近未解决的一天开始；遇到不更暖就停止

### 05 name
frame：canvas
画面：第6天32与待解决区35、31、30保持关系；先从30向左显示温度不升的顺序，再在对应术语起音后显示名称；不播放正式执行。
旁白：所以温度从早到晚不升，最近一天放在末尾。单调栈就这样保存下标，先检查末尾，解决后再移走。
屏幕文字：35 ≥ 31 ≥ 30；单调栈；保存原来的下标
