# Agent 入门视觉调度

本期用同一合成订单8124贯穿20镜。只读查询和建议，不执行退款。

## 固定空间与颜色

- 全片1920×1080、30fps，使用共享pageTheme深色底。上方标题、右上品牌、下方单层字幕。
- 请求/结果图的三节点固定为模型x370、执行程序x960、外部查询x1550；主体y350–605，载荷在下方y700流动，避免穿过文字。
- 金色用于请求、未核实条件；蓝色用于提供给模型的信息；青色用于已返回/有依据的步骤；灰色是未开放能力，不能仅凭颜色表达语义。
- 数据包代表传递中的信息，不移动或抹去原始订单对象。请求抵达执行程序后才校验/查询；结果包抵达模型后才显示已收到。
- 模型、工具、智能体的首次命名仅在04/07/14镜首句实测起音入场；前镜不通过全局标题提前露出。

## 时序与动作

真正句起点从storyboard的cueFrames.sentences读取。术语首现从cueFrames.labels读取。程序动作在对应句区间内按缓动计时，是timerDriven演示，不声称逐字挂词。src/motion.ts导出关键状态与标签事件，qa脚本在事件前后取样。

| 镜 | 主要动作与状态 |
|---|---|
| 01 | 回复建议进入左侧；右侧订单状态保持未执行，焦点沿两者切换。；保持订单记录不变；突出建议与执行的冲突，不提前给出循环答案。 |
| 02 | 同一订单8124缩退为稳定右侧锚点；用户问题进入。；建议与执行两个结果位分开，当前均未核验。 |
| 03 | 只读查询的范围线包住订单查询和规则查询；写操作区域不接通。；显式保留示例声明与退款未执行，逐步让规则对象入场。 |
| 04 | 模型在左侧进入；用户问题流入模型，回复从模型流出。；查询记录位保持空；回复不能改变右侧订单的真实状态。 |
| 05 | 一般说明退出当前焦点，回到订单8124的问题。；订单事实槽为空并标未查询，等待真实查询返回。 |
| 06 | 应用执行程序在中间入场，向左交付问题及可用能力说明。；右侧只引入查订单、查规则两个入口；退款执行没有被提供。 |
| 07 | 工具首词起音时标签出现；显示两种查询能力。；调用请求从模型到执行程序，执行路径再到查询入口，禁止模型直连改订单。 |
| 08 | 请求载荷8124从左抵达中间，先停在待校验。；编号与读取权限依次通过后，查询才抵达订单记录；不读取其他订单。 |
| 09 | 同一订单卡揭示签收3天，查询结果进入返回路径。；使用情况字段保持未知；不擅自填未使用。 |
| 10 | 查询结果从右经中抵达模型，订单原卡保留，数据包只代表返回副本。；两个缺口逐个显示；模型下一动作选择位从待定转查规则。 |
| 11 | 查规则请求从模型经执行程序抵达同一示例政策入口。；规则原文从右经中返回模型；只显示当前规则。 |
| 12 | 示例规则逐条出现，签收3天与期限7天对齐后仅时间条件确认。；使用未知保持金色待核实，申请资格仍待判断；不提前显示可申请。 |
| 13 | 询问从模型经应用送向用户，同一订单仍在右侧。；工具路径暂停，明确等待补充；不继续自说自话补造使用状态。 |
| 14 | 智能体首词起音后，用外边界包住模型、执行程序及反馈连接；顺次回看请求、执行、结果三段。；突出下一步受已知结果影响，仍保留等待用户状态；不画隐藏思考文本。 |
| 15 | 用户回答经应用抵达模型，使用字段显示用户补充未使用并标来源。；本轮输入汇合已查询订单、对应规则和用户补充，不重新复制三个大面板。 |
| 16 | 时间条件与用户补充依次汇入建议，显示按当前资料可申请。；建议确认后，订单退款状态仍锁定未执行，禁止变为已退款。 |
| 17 | 明确切到同一咨询的架构对比示意，不重演已退款业务；显示程序预定查订单→查规则。；使用情况已知/未知的条件分支依次展开，两条路径都由预写规则控制。 |
| 18 | 对比预写路径与模型根据返回选择，明确箭头归属；不靠是否有分支判Agent。；应用外边界保持只读与停止条件；模型选择不能穿透限制。 |
| 19 | 回到同一订单8124的事实视图，写动作入口仍未提供，不实际执行。；模型完成文字淡出核对路径，订单实际未执行成为判据；建议完成和退款完成分列。 |
| 20 | 顺次点亮本片确实发生的查询请求、执行、返回与补充，不伪造未执行步骤。；落到可申请建议和退款未执行两个准确结果；原创片尾入场，不说下期见。 |

## 重要边界

- 09–14：签收3天，使用未知，资格待判断。15收到用户补充后才出现未使用，保留用户来源说明。
- 16：只给“按当前资料可以申请”的建议；退款始终未执行。
- 17明确切到架构对比示意，预写流程具有已知/未知条件分支；18比较谁选下一步，同时保留应用权限/次数边界。
- 14回看已发生的查询，不表示13等待期间继续执行。
- 19核对真实结果，不展示本片未接入的退款操作；20总结建议完成与未退款两项事实。

## 预演接口

从remotion运行 node scripts/qa.mjs /tmp/agent-intro-qa --shots=08,10,11,13,14,15,16,17,19 --motion --no-captions。首次结构预演可以读src/placeholders/storyboard.json，必须标临时时序；有真实storyboard后自动优先读取，冻结前需重新生成并检查。

qa导出frames.json含素材源码哈希、是否临时时序、事件前后帧、字幕开关和COPYFIT日志。连续clip为无声视觉检查，不当作听辨。
