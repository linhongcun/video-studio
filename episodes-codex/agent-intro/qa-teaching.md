## 已向编剧同步的教学约束

1. 固定工作流也能调用模型和工具，并包含分支与重试；不能把“用了工具”或“出现分支”单独当成 Agent 定义。
2. 核心动态应分别出现：模型提出请求 → 执行程序实施调用 → 工具结果回传 → 模型在允许范围内决定下一步。模型不直接连接数据库、不凭一句话完成退款。
3. 同一退款咨询贯穿全片，先建立订单、规则、信息缺口和建议状态；只读查询和建议不能被画成资金已经退回。
4. “停止生成/本轮结束”“缺信息待补充”“业务目标达成”应区分。提问、失败和达到应用限制均可能结束本轮。
5. 本期是概念入口：先说明模型与应用程序，不要求前置 MCP、Skills、Schema、RAG 或框架知识；实现深度留到后续视频。
