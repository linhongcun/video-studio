## 能力边界

当前未发现可用转写/音频理解工具、已安装的ASR包或模型缓存。本轮未执行逐字ASR、发音/变调听辨或全片人工听辨，也没有基于识别结果判断实际口播。没有绕过网络限制或声称旧版语音检查覆盖本片。

`words.json` 字符兼容字段是整句包络，只有句首有共享声学起音，不是内部词级对齐。送模文本、波形与PCM匹配不能证明实际读词或发音正确，更不能证明观众已经理解设计思想。动画与实际成片仍须独立检查，配音装配报告不替代最终媒体审查。
