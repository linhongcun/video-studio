# 《AI智能体，下一步怎么选？》

A01 / EP.22，issue #131，第三版开场交互界面修订，制作目录agent-intro-v3；站点slug仍为agent-intro。2026-10-24按用户后续建议只修改01开场为退款咨询对话界面；复用V2全部旁白和237帧后的已验收内容。V1和V2制作历史保留。

- 唯一问题：什么是AI智能体，它怎样根据返回结果决定下一步。开头以“查资料却突然问人”的真实动作悬念引入，结尾同句回应；不以申请建议与未退款制造第二条冲突。
- 11镜22句；按正常配音与完整性评估时长，不加速凑秒数。首词术语只有智能体01、模型02，不硬凑第三标签。
- 同一合成订单8124：签收3天、使用未知；示例政策是签收7天内且未使用可申请；用户补充未使用后，按当前资料给建议。政策与数字以“示例”角标标明，不当作法律或真实商家规则。
- 画面聚焦“已知信息、当前缺口、本次选择”随结果变化，查询时才展开请求→程序执行→结果回流，返回后收回；不持续挂三大静态框，不做装饰进度条或页内阶段进度标记。
- 模型不能越过程序直接执行查询；用户回答保留“用户补充”来源，不能画成系统独立核验。片尾仅一句说明本例未执行退款，其他范围边界移文章。
- 首5秒是同一过程的悬念预览，不泄露“使用情况未知”答案。第二镜显式回到第一次查询；后文按返回结果引发的下一选择推进。
- 固定工作流比较、权限和停止条件放文章；不在片中形成第二条讲解主线。机制动画不宣称已运行真实模型、实际退款或成功率实验。
- 旁白状态：独立结构编辑复核后冻结；后续改旁白须先协调停止相关制作。资料实际重读记录见research.md。
