# Agent 入门 V2 视觉主线

本版仅回答：AI智能体根据返回结果，怎样选择下一步。11镜22句；旧V1冻结目录不改。

## 画面组织

- 第一帧给主体题名与目标“订单8124能否申请退款”。“智能体”文字仅随01首词实测cue出现。
- 0.3/1.3/1.9/3/4秒演出请求、结果收回和转问用户的悬念，不展示实际字段，保持为什么反问的疑问。预告查询也经过执行程序。
- 正片02首句就发起请求，到执行程序校验，再到查询来源；最终用真实配音绝对帧确认首15秒已开始正片查询。预告不充当该证明。
- 全片无章序、无章节点线、无装饰进度条。上方只保留同一目标、当前问题与品牌。
- 03/06/09/11同一三栏主体：已经拿到 → 还缺什么 → 下一步选什么。新事实进入已知区、当前缺口提升焦点、动作实体退出/进入；不是三个不变的长段落。
- 02/04/07/08/10只在需要解释传递时展开模型、程序、查询/用户三节点。请求与执行分段，结果抵达模型后才显示收到；已知资料通过简短上下文保留。
- 05只呈现本单查询结果与新返回规则，用两个逐项出现的条件准备06的选择变化。
- 10回看已发生的分工，边界包含模型和应用执行控制，不把智能体只圈成模型。11回到缺口，兑现开头，不再加退款未执行的结论页。

## 状态边界

- 03签收3天、使用未知；04因为缺规则而查询；05规则为7天内且未使用。
- 06只确认时间条件；未使用事实仍未知，所以当前动作改询问。
- 07问题送用户后停轮，不继续空转。08使用信息只标来源“用户补充”，不是独立查证。
- 09按当前资料给可申请建议；退款未执行仅角落事实，不争夺主线。
- 10/11回看明确标记为解释，不作为第二次业务执行。

## 计时

动画按真实cueFrames.sentences区间计时；术语按labels的声学起音帧入场。动作计时是可观察流程演示，不是逐字ASR或隐藏思考。src/motion.ts提供实际状态阈值。QA显式渲染全片0/60/150/450帧和正片首次查询事件前后，记录绝对帧及是否小于450。

## 预演阶段

有真实storyboard时自动优先读取；否则使用src/placeholders临时时序，报告必须保留provisional=true。只有编辑叙事与真实时序闸门通过后才能正式冻结编码。无字幕小样在selectComposition与composition.props中同时明确设置隐藏字幕，并从实际输出抽帧确认。
