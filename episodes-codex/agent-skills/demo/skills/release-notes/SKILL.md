# 发布说明

按用户可观察的变化组织版本说明，分别写新增、修复和已知限制。每项保留对应变更来源，删除没有实际完成的宣传性结论。

这是发现阶段的无关候选。本演示不会激活这份正文；不能把它画成随 API 审查一起进入模型上下文。
