# MQ07 发音与文字

- 音色沿共享冰糖，不自建TTS算法；当前未配音。
- Kafka按既有词典读“卡夫卡”；源码/画面保留Kafka。
- C一到C十二：C读字母“西”，指按member.id排好序后的画面C01…C12，不是client.id。
- P0/P1旁白说零号/一号分区；E01旁白说事件一，画面保留E01与订单7042。
- RangeAssignor旁白说范围分配；classic说经典消费组。Fetch说读取请求，poll说拉取返回，必要英文在动作建立后上屏。
- 4/s→各区2/s；完成能力各区1/s；降至1/s逐秒交替两区，均为教学假设，不宣读成实测结果。
