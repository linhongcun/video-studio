# EP.21《分布式事务，几种方案到底怎么选？》（修订版草稿）

2026-10-24，响应用户对现行EP.21只讲可靠消息、不够全面且边界不清的反馈。新稿经结构与独立技术复核后进入配音，实际检查记录见新版QA。

- 五条常见工程路线：2PC/XA、AT、TCC、Saga、可靠消息；可靠消息明确拆开Outbox与RocketMQ事务消息的机制。它们不是同层术语，不将XA当成独立于2PC的同级算法，不将AT与任意自动回滚等同。
- 本期按用户要求扩展术语和章节，不沿用旧片“仅一条可靠消息主线/2–3术语”限制；保留渐进揭示与单一视觉焦点。38镜、每镜两句，时长由实际配音决定，不硬压到固定长度。
- 统一订单8124、初始库存4、付款200。Saga失败分支明确另起缺货示例，库存重置为0；若显示账户余额，使用1000→800→退款1000；每次改用新的成功/失败分支均有简短“另一种结果/示例重置”，不把不同方案串成同一次执行。
- 全部数字为示例。深色全屏canvas，不造浏览器/应用外壳，不画物理锁；保持对象位置和状态颜色，不用字幕替代状态变化。
- 首次方案名称放句首：04“两阶段提交”“XA”；09“AT模式”；14“TCC”；19“Saga”；24“可靠消息”；25“Outbox”；29“RocketMQ事务消息”。实际标签时序待配音后按共享声学起音确定，不预造字级时间。首次名称出现前不在章节导航/总览里提前暴露。
- 各镜技术主张和边界须与research-overview-v2.md独立研究结论共同审读；配音前核心技术与修订措辞已独立复核。TCC空回滚/悬挂、AT脏写校验、消息回查超时策略的细节放文章。
