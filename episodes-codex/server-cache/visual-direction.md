# 动态表达设计

2026-10-24（北京时间）。按EP.16第二版经验：同一对象原位延续，当前操作引导焦点，数据随动作变化；其他信息退为上下文。字幕关掉以后仍应看到读取、返回、填充、写入或撤除的过程。

## 稳定空间与语义

- 应用位于x320，临时副本x950，数据库原记录x1560；同一商品7042贯穿。首镜尚未引入缓存时留空中间位置。
- 青色表示可用/确认的新结果，金色表示待处理或旧副本，红色表示错误/失败；颜色不是唯一线索，文字和值同时区分。
- 请求是沿路径移动的圆点，返回的数据带数值移动。查询原记录由应用发起；缓存只被应用读取/填充，不把缓存误画成自动向数据库查询。
- 对象只在需要时进入；不出现实物设备、浏览器壳、假应用窗或大面积白底。字幕带y925起，与主体留开。
- 每个镜头的第二句起点来自voice/build.json，cueFrames.sentences用于当前因果阶段；正式术语以共享声学规则定位，不估计句内字时间。
