# EP.08《数据库明明有数据，为什么还要再存一份？》Codex重制

2026-10-24（北京时间）。本稿重新设计请求路径与同一商品数据的因果动画，沿用现行规则和EP.16第二版已验证的渐进揭示经验。

- 一条主线：同一商品的重复读取如何通过服务器一侧的临时副本减少数据库访问。
- 全片为深色全屏canvas；不是实物设备，不套假浏览器。对象是应用、临时副本、原记录与请求。
- 商品7042、199元、三次请求和读取次数全为教学示例，不是性能测量。
- 术语仅数据库、服务端缓存、缓存命中，首次均独立句首；内部词时间不冒充ASR。
- 缓存适用条件、过期和清除的边界必须保留；不承诺所有请求变快。
- 每镜两句完整旁白，字幕逐字采用本稿。出处见research.md；片外补充在article.mdx。
