# Redis Cluster 因果动画

真实EP51，固定Redis系列冷银灰背景、Redis红强调、石墨字，导入共享不可变style-v1而不修改它。片头没有黑屏。背景不承担事实，当前节点、消息与槽归属承担动作。

## 空间与身份

主甲、主乙、主丙固定三列，上方各槽范围；对应副本在同列下方。节点使用Redis原始标记配中文角色；原主离线变灰但不删除数据或身份。投票人是原三个持槽主节点；候选甲副本不进入选票分母。焦点移到甲副本时乙丙保持可定位，不能变成两名Sentinel。

故障报告为细虚线消息，授权请求和回复为粗实线定向消息并带轮次；消息抵达才更新接收者状态。票计数必须由已接收、去重、当前轮次的授权驱动，不能旁白一说就提前跳2。槽徽标只能在多数授权之后从旧归属转到新主位置，其他节点的槽表在公告到达后更新。

## 情景分叉与复位

01–09为一个连续成功过程；10用明确“独立对照”先恢复参选前状态和空票，再表现一票不足；11明确回到已完成的成功分支，解释原来可能存在但未复制的末条写入。它不把少数侧突然恢复并成功作为同一过程，不把旧主数据消失说成磁盘被删除。

## 实际检查安排

配音前以估计时序做关键小样，单独标注PREVOICE；真实配音后重采。至少检查报告抵达、两票前后、晋升前后、槽归属通告抵达、独立对照复位及字幕合成。中间态的移动消息不得穿过节点文字；角色和状态不能覆盖槽范围，底部字幕带独立。

文章图位在真实分镜装配后按确定帧写入并冻结，再从最终媒体抽取同帧。片尾两项原题/机构列表5秒，使用同色资料adapter，最终编码真实limited BT.709转换，不仅修改色彩标签。
