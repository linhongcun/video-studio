# EP51 / Cluster 制作说明

正文1920×1080、30fps，12镜24句、真实整轨4466帧。银灰/Redis红/石墨字沿共享不可变redis-video/style-v1；Header只传短题Cluster、真实EP51及当前章名，避免内部固定间距冲突。

固定三主三副本，原三主为投票分母，甲副本为候选。模型JSON驱动故障阶段、轮次、角色、票数与槽归属；动画sceneTiming读取真实voice localStart/localEnd，消息抵达时才提交相应接收状态。正常投票模型的身份集合不声称是真实ACK接收侧去重表。

主甲/乙/丙位于同一水平参照，甲副本保持下方原位。乙丙非关键副本在角色建立后退出主体，不能被误当投票人。报告虚线、请求/授权实线；场景10显式独立复位、场景11显式回成功分支。槽归属标记沿左侧空走廊转交，避免覆盖主节点身份与标签。

本期不展示正文代码，不附完整算法题解卡；主线收束后由默认入口追加两项原题/机构资料页，5秒静默。渲染先H.264/AAC人声，再真实full-range BT.601→limited BT.709转换、共享BGM混音，最后同色资料页；不只修改编码标签。

声音复用共享prep/gen/build/assemble/place/onset；24句首轮a保留。ASR未执行，句子内部字符仅兼容包络，不冒充逐字对齐或全片人工听辨。预检、产品实验、有限模型与真实媒体分别记录，用户观看结论不预记。
