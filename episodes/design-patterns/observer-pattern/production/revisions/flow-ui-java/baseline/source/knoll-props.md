# 观察者模式 · 制作说明

2026-10-25（北京时间）。制作入口为本目录，Remotion依赖按本期锁文件在`remotion/node_modules/`真实安装，不引用已清理的旧站制作目录。12镜24句、1920×1080、30fps，真实配音装配为4979帧，约165.97秒；媒体与上线结果以正式检查报告为准。

## 画面与主线

主体是同一程序内的示例订单17，状态依次为待付款、已付款、已发货。先建立商家处理订单的功能场景，再展开职责关系。订单来源在左侧，当前接收者名单放在其边界内部；摘要与变化记录固定在右侧。名单属于来源所维护的数据，不是独立执行者或消息队列。

直接安排阶段在订单处理内点名摘要和记录；订阅阶段改为接收者向来源登记。来源仍持有名单并依赖共同通知约定，不能画成依赖全部消失。共同约定是订单号与新状态，发出的内容是变化事实，各接收者负责自己的显示或留痕。

03以反向登记箭头把接收关系加入名单，04按句首声学cue引出“观察者模式”。05先更新来源状态，再开始通知；05末尾的同一条消息停在路径45%，06从相同位置继续，摘要处理完才通知记录。本例依次通知仅为本实现的选择，不是模式统一保证。

08摘要退出后从名单移除并删除其通知路径，原卡保持位置，标“最后收到·已停止接收”，保留已付款旧值并说明它不代表当前状态。09同一订单变为已发货，只有仍在名单的变化记录收到并新增第二条事实；摘要不刷新，也不清空历史数据。10回收共同约定不变的维护范围，11交代生命周期成本与可靠投递边界，12先给单个固定接收者的直接通知选项，再回到本例最终关系。

## 动作、文字与时序

动作只使用`src/motion.ts`的句级真实起音区间，同一份beat被渲染和QA事件采样共用。字幕来自冻结分镜，逐句对应口播；语音内部没有词级ASR结论。03“订阅”、04“观察者模式”、08“取消订阅”均按句首真实cue出现并完整保留至少63帧。

消息令牌宽154px，登记令牌宽140px，全部令牌的边界夹在来源右侧1090与接收卡左侧1320之间，避免在中间态压住名单或尚未更新的旧值。发送方指向接收方，登记/取消动作则由接收方指向来源。当前值、最后收到的值和历史事实分别标明，不用业务统计数字代替状态事实。

深色页身来自共享`episodes/_shared/theme/pageTheme.ts`。不使用比喻、实物设备、假浏览器外壳、密集类图、代码语法教学或装饰进度条。主要章节先口头承接，再开始新动作；标题不能代替过渡旁白。

## 预演、封面与编码

在本期`remotion/`目录执行`npx tsc --noEmit`。`npm run qa -- out/<名称> --no-captions`生成真实状态PNG，最终composition props明确为隐藏字幕；`--ranges=03:03,05:06,08:09`生成登记和两段跨镜连续MP4。QA分别检查登记方向、先变状态后通知、摘要与记录依次响应、取消后历史值保留，以及第二次仅记录接收。预演中的问题与修订按实际目录保留，不用新源追认旧小样。

`npm run covers`通过本期Cover.tsx和covers.json输出16:9、4:3、3:4的PNG/JPG，3:4 JPG同字节复制为poster.jpg；逐份看真实产物并核对4:3安全区x315..1125、底边小于918以及水印区。COPYFIT无溢出只是基础检查，仍须查看中间态。

所有负责人停写后冻结实际源码、选中takes、音轨、分镜及共享依赖；正式编码前后核对完整SHA。正式渲染沿用`npm run render`，先H.264/1080p/30fps输出，再调用共享Wallpaper混音到目标−16LUFS；使用空间充足的短路径TMPDIR与共享渲染锁。最终媒体解码、响度、字幕、实际MP4状态、站点与线上完整SHA按报告记录。未完成的逐字ASR、完整人工听辨和初学者实验不得写成通过；平台新发不在本轮授权内。
