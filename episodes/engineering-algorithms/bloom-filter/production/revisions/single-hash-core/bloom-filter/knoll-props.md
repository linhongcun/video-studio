# EP39 单位置主线制作说明

9镜18句，保持公开slug与EP39身份；抽象元素A/B/C/D、8位数组与单个活动计算路径。主线A/B共用3，D查7为0，C查3为1，反例直接清3误伤B。08为独立完整重建的两位置对照，A3/2与B3/1写完才查C3/5；不对旧位图直接换查询规则。

配音使用共享MiMo冰糖、全新takes与整轨/起音，不复制共享算法。实际句窗口由voice/build.json和storyboard.json记录。帧率30、正文1920×1080；共享pageBg/pageInk、水印与逐句字幕。术语按句首真实声学起音进入。没有逐字ASR或全片人工听辨，不以数值核验代替这些能力。

按实际配音检查状态抵达、停留和相邻镜连续性；08第一句重建、第二句查询。封面16:9/4:3/3:4均实际生成并独立检查，4:3遵守安全区。正文与封面不得COPYFIT或靠自动缩字掩盖溢出。

默认render入口为render_with_references.py，正文H264混音目标−16 LUFS、真峰值−2 dBTP，附录original-title-quote默认一页5秒。编码前冻结所有实际输入，原版冻结字节保留。最终媒体完整解码、实际关键帧/音频/资料卡检查和站点、线上核验结果分别写阶段QA，不在本说明中预记通过。
