## 各章画面
1. **hook** ①第 0 帧即封面：两行大字「大促一到」/「下单怎么就卡住了？」+ 手机下单页，「下单」按钮变灰、转圈（大字 0–36 完整、36–45 淡出，字幕 45 帧进）②订单小票一张张飞进同一台机器旁的同一张表
2. **bridge** ①主库（赛场）+ 从库（电视）+ 看的人（EP.18 图）：信号线把画面送到电视，读分走了 ②下单小票全挤向主库，电视变暗，钟弹出
3. **station** ①一个快递驿站（青色门头）推近 ②包裹堆成山 → 货架塞满 → 记账员满头汗、单子乱飞
4. **table** ①站里一排排摆出同款空货架；四色贴纸包裹落到各自颜色的货架，每件只落一处 ②同一个库（青框）里四张结构相同的表（下面色条区分）→ 分表
5. **database** ①四个彩色货架前只有一个忙不过来的记账员 ②开出红 / 蓝 / 绿 / 黄四个分站，各有货架、各有记账员 ③每站下面一台机器，下单小票分四路彩色信号线下去 → 分库
6. **key** ①四个分站；蓝贴纸包裹的贴纸被圈出，信号线指向蓝站，其余站变暗 ②穿蓝衣服的收件人，他的包裹一件接一件都进蓝站 → 分片键
7. **strategy** 左右分屏：左＝日历（今天那格亮）→ 今天的包裹全挤进红站 → 按范围；右＝打散图标 → 各色包裹平均落到四站 → 按哈希
8. **vertical** 左右分屏：左＝三站货架一样（水平拆分）；右＝绿站放生鲜、黄站放大件（垂直拆分）
9. **xquery** ①拆开后四站 + 钟（麻烦来了）②秤上一件包裹（找最重的）→ 取件员跑过每个站、每站冒出它最重的那件 → 汇总单 → 跨片查询
10. **xtx** ①红站把包裹沿信号线转给蓝站，红站账本记上（转出）、蓝站账本记上（转入）②两本都记上 → 都不记 → 信号中途断（断线图标、包裹停在半路）→ 红站有、蓝站红叉（账对不上）→ 钟 → 分布式事务
11. **id** 红站、蓝站各自给包裹贴同样的条码签 → 两张签撞到一起（闪光）
12. **reshard** ①再开黄色新站，手推车把包裹从旧站拉过去（搬家）②一台机器 + 一个驿站 + 一个不慌的记账员（单台够用，先别拆），推近
13. **recap** 一个库里四张表（分表）｜四色分站（分库）｜蓝衣收件人 + 蓝贴纸包裹（分片键）→ 断线 + 钟（都有代价），全镜推近收尾
