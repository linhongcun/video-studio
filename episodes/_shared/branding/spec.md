# 「IT小村」频道水印 + 片尾卡规范 v1.2.0（Miyazaki）

导演定稿：**右上角常驻水印（40%）+ 中央淡水印（8–10%，逐镜头选位）**。四角轮换方案已放弃。机读版见 spec.json。

## 字体
Noto Sans SC Bold（700）。SIL OFL 1.1 授权，免费且可商用（Google Fonts）。与正片字体一致。

## 1. 右上角常驻水印
- 文字「IT小村」，32px，700，颜色 #E5E7EB，不透明度 0.4，无底板、无描边。
- 锚点：右上角 (1840, 80)，右对齐、顶对齐，紧贴 80px 安全边。实测字形框约为 x 1745–1840、y 90–122。
- 留空区 clearZone 为 x 1700–1840、y 80–130，镜头内容（不含字幕）不得进入。
- 显示范围：正片第 0 帧淡入（0→15 帧），一直显示到正片最后一帧，并在片尾卡开始前 12 帧淡出。**片尾卡上不显示。**
- 层级：在所有元素之上（含字幕，两者位置不重叠）。
- 没有隐藏例外：EP.01–04 全程显示。

## 2. 中央淡水印
- 文字「IT小村」，120px，700，颜色 #E5E7EB，不透明度 0.09（允许 0.08–0.10），居中对齐，占位框按 380×150 计。
- 层级：在镜头元素**之下**、背景之上，因此不会盖住文字或图表。
- 选位规则（center_place.py）：
  1. 取镜头全部非字幕元素的框。居中文字按估算字宽收窄，然后外扩 24px。
  2. 再加上右上水印框。
  3. 在 x 80–1840、y 140–860 内以 20px 步长找 380×150 的空框，取离画面中心 (960,480) 最近的。
  4. 找不到空框，本镜头就不显示。
  - 结果写在 center_placement.json，格式为 EP → 镜头 id → {x,y} 或 null。
  - 选位是静态的，按镜头内全部元素算，偏保守。
- 淡入淡出各 15 帧，随镜头进出。片尾卡上不显示。
- 对比度：即使盖在上面，在卡片底色 #111827 上，最暗正文色 #9CA3AF 的对比度从 6.99 降到 5.44，红色 #F87171 最坏为 4.99（均为 10% 时），都不低于 4.5。放在元素下面则完全不影响。
- **找不到空位、需要隐藏的镜头共 9 / 68 个**：
  - EP.01：connect-2（1/24）
  - EP.02：intro-1、plaintext-2、asymmetric-2、handshake-3、integrity-1、recap-1（6/19）
  - EP.03：无（0/14）
  - EP.04：set-cookie-1、session-1（2/11）

## 3. 片尾卡（60 帧 = 2 秒）
- 接在正片最后一帧之后，总帧数 +60。
- 背景 #0B1020，与正片一致。
- 文字「IT小村 · 原创」，72px，700，水平居中，中线 y=500。
  - 分色：「IT小村」#22D3EE，「 · 」#6B7280，「原创」#E5E7EB。
- 下划线：宽 360、高 6、圆角，颜色 #3B82F6，y=560。从第 6 帧开始画出，持续 15 帧（drawProgress，easeOut）。
- 整体第 0–12 帧淡入，第 47–59 帧淡出到背景色。
- 音频沿用配乐尾音，无旁白。两种水印都不显示。
