# Kafka正文与参考资料入口

Kafka正文与封面共用不可变的`kafka-covers/style-v1.json`字体和配色。每集有独立修订、真实配音/时序、模型与输入清单，旧RabbitMQ制作工程和冻结不改写。背景副本和实际导入组件一并冻结，不以会增长的catalog作为旧片视觉输入。

`render.py`通过私有函数命名空间选择本目录的`references.py`，复用原有`render_with_references.py`的来源预检、冻结、正文渲染与发布媒体校验。参考卡仅替换配色，原题/署名排版和完整正文帧/时间戳、AAC包/时序、PCM验证仍由现有引擎执行，不修改其源码或全局状态。

单集默认npm render接入本入口，正文包含实际讲解，之后自动追加每页最多4项、每页5秒的原题/机构资料卡。`--verify`读取冻结输入并复核最终媒体；制作和独立动态图义、语音能力范围、播放器与上线检查另外保留，不以工具通过代替实际观看。
