# 《AI 能回答问题，怎么才能真正帮你办事？》

2026-10-24，A01 / EP.22，issue #131。本文是概念入门：先区分回答和执行，再认识模型、工具与智能体的反馈循环。

- 20镜、40句、5章；每镜两句完整旁白，时长由实际配音决定。
- 同一笔合成订单8124：签收3天、是否使用未知；示例规则是签收7天内且未使用可申请。用户补充未使用后，只形成有依据的申请建议；退款状态始终未执行。该政策是教学设定，不代表法律规定或真实商家政策。
- 只引入模型04、工具07、智能体14三个术语，首次均在句首。画面不在对应起音前显示标签；智能体在文章中说明英文名Agent，旁白统一读智能体。
- 模型在左、应用执行程序居中、查询入口及同一订单/规则在右；用户补充只改变已知信息，不改变退款业务状态。
- 固定工作流可以有条件分支、工具和模型调用；本片按控制流来源作实用区分，不声称这是Agent唯一公认定义。
- 画面只展示调用请求、应用检查、执行、返回和用户补充等可观察过程，不把阶段说明冒充模型隐藏思考。
- 本片是可追踪的教学动画，不声称已运行真实模型/订单接口。资料与适用边界见research.md；代码实战、RAG、MCP、Skills、持久恢复留后续选题。
- 文章提醒：用户陈述未使用仍是待业务核验的信息；可申请不等于批准或到账；写动作还需权限、业务校验和实际结果核对。
