# EP.10《订单已提交，为什么还没处理完？》

2026-10-24 Codex重制。依据今天EP15–17经验，以同一任务7042贯穿可靠入队、处理、确认；数值和容量均为教学示例。

- 一条主线：提交状态为什么早于处理完成。仅讲消息队列、处理确认、削峰三个标签，标签在独立句首实测起音后出现。
- 全屏深色canvas，没有实体队列、实物设备或假应用窗。请求和任务用抽象数据记录，身份随移动连续。
- 确认边界：发送端确认与处理端确认分开；示例假定可靠保存配置并开启发送端确认及手动处理确认。无绝对不丢失、严格全局FIFO或恰好一次保证。
- 动画承担解释：保存后返回、成功后确认、无确认后重投；复杂实现和持久化边界留在文章。
- 实读出处与访问日期见research.md；句级声学起音不能冒充逐字ASR。
