# EP.17《两个人抢最后一件货，听谁的？》

2026-10-24 用户明确要求选择并开始下一期，选定 #69。制作本地待审版；站点及平台发布另按后续指令。

- 只讲同一数据库内，一件商品库存1，甲乙各买1件；不模拟真实购物界面。数字均为教学示例。
- 前半是普通读、应用算数、绝对值写回造成的错误示例，不说数据库UPDATE不加锁。后半采用显式事务内加锁读取、检查库存、修改、提交；乙等待后读新结果再检查。
- 术语仅丢失更新、行锁，首次均在独立句首，标签至少63帧。事务和提交沿用上期，不另开分支。
- 不承诺先到先得或FIFO；示例仅甲先拿到锁。已存在主键记录精确查找是本期范围，不概括所有查询只锁一行。
- 深色全屏canvas，按需进入对象、移动焦点、状态随动作改变；无实物锁、假应用窗和常驻双大表。
- 代码一处：SELECT stock FROM goods WHERE id=7042 FOR UPDATE;。显式事务由画面中文标注和旁白交代。
- 官方依据和逐项边界见research.md；不将无ASR的句级边界当逐字识别。
