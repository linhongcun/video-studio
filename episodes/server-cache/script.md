- 系列：后台缓存
- 标题：数据库明明有数据，为什么还要再存一份？
- 主线：同一个热门商品页平时完整、高峰转圈 → 商品、价格、库存、订单存在数据库 → 每次打开都查，同一行反复查询 → 数据库忙、查询排队，页面等商品数据 → 热门数据在服务器内存里另存一份，叫服务端缓存 → 先看缓存，有就直接用，叫缓存命中 → 没有才查数据库并存进来 → 重复查询减少、页面变快 → 回答开场 → 三行回顾 → 讨论题 → EP.09 预告。
