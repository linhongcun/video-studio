# 第八期读法表（只改送给 TTS 的文字，字幕不动）

- 服务端缓存：fú wù duān huǎn cún
- 浏览器缓存：liú lǎn qì huǎn cún
- 数据库：shù jù kù
- 仓库：cāng kù
- 现切现配：xiàn qiē xiàn pèi；切好：qiē hǎo
- 备菜台：bèi cài tái
- 过期时间：guò qī shí jiān
- 重新备：chóng xīn bèi
- 撤掉：chè diào
- 长队：cháng duì
- 一趟：yí tàng
- 负载均衡：fù zài jūn héng
- Cache Hit、Cache Miss、EXPIRE：只上屏，不要读

## v0.12.1 新增（旁白里念出术语）
- 命中 / 没命中：mìng zhòng（「中」读四声）；风险高时只改前后说法，词保留
- Redis：读作「瑞迪斯」（ˈrɛdɪs）
- TTL：按字母逐个读 T-T-L
- CDN：按字母逐个读 C-D-N
