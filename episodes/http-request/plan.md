# 制作方案：《一次 HTTP 请求是如何完成的？》

- 项目目录：/workspace/video-studio/http-request/
- 观众：对互联网开发感兴趣的初学者
- 规格：约 30 秒（目标 30s = 900 帧），1920×1080，16:9，30 FPS
- 风格：简洁现代 2D 科技动画，深色背景 + 高亮蓝/青，扁平图标（浏览器窗口、服务器机柜、数据包）
- 语言：简体中文解说 + 简体中文字幕（字幕与旁白逐句对应）
- 技术栈：HTML/CSS/React/SVG + Remotion（仅此）

## 内容范围（4 段）
1. 开场提问（约 4s）：输入网址、按下回车，背后发生了什么？
2. 浏览器发送请求（约 8s）：请求包含方法(GET)、路径、请求头，像一封信飞向服务器
3. 服务器处理（约 7s）：服务器收到请求，查找/生成内容
4. 返回响应（约 7s）：状态码 200 OK + HTML 等内容飞回
5. 浏览器展示 + 收尾（约 4s）：浏览器解析渲染出页面；一句总结“请求—响应”
不讲 DNS、TCP、TLS，可用一句“（省略网络连接细节）”带过或完全不提。

## 规则
- 每阶段交付后通知导演，导演确认定稿才进入下一阶段。
- 配音：优先用盒子上可用的中文 TTS（如 edge-tts / espeak-ng 等），按实际时长对齐字幕；若 TTS 不可用，明确报告，可先出“字幕 + 音效”版本并说明，不得虚构。
- 渲染失败必须如实报告错误日志。
- 技术表述要准确：HTTP 是请求—响应协议；GET 是请求方法；200 OK 是成功状态码；响应体常为 HTML。
