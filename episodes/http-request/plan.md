# 第一期重制方案：完整版《从输入 URL 到页面展示，发生了什么？》

目标：观众看完能把一次网页访问从头到尾讲清楚——结构清晰、覆盖完整、经得起深入提问。

## 完整主线（视频与图文共用的主线，8 步）
1. URL 解析：协议/域名/端口/路径；非法输入走搜索；HSTS 强制 https
2. 缓存检查：浏览器强缓存（Cache-Control/Expires）命中则直接用
3. DNS 解析：浏览器缓存 → 系统/hosts → 本地 DNS 服务器 → 根 → 顶级域 → 权威（递归 + 迭代）
4. 建立连接：TCP 三次握手；https 再做 TLS 握手（协商版本与密钥、校验证书）；HTTP/2 多路复用、HTTP/3 基于 QUIC 一句带过
5. 发送 HTTP 请求：请求行、请求头（Host、Cookie、If-None-Match 等）、请求体
6. 服务器处理：CDN/负载均衡/反向代理 → 应用服务器 → 静态文件或动态生成
7. 返回响应：状态码（200/301/304/404/500）、响应头（Content-Type、Cache-Control、Set-Cookie）、响应体；304 协商缓存
8. 浏览器渲染：解析 HTML 成 DOM、CSS 成 CSSOM → 渲染树 → 布局 → 绘制 → 合成；JS 阻塞解析（defer/async）；子资源再发请求；连接 keep-alive 复用或四次挥手关闭
