# 脚本 v2：《从输入 URL 到页面展示，发生了什么？》（完整版）

- 依据：`episodes/http-request/plan-v2.md`
- 总时长约 2.5–3 分钟，开场 + 8 章 + 结尾串讲，共 10 段
- 字数按汉字和英文字母/数字计（不含标点和空格），语速按每秒约 4.2 字估
- 字幕与旁白逐句对应；画面复用第一期的浏览器、服务器、信封，新增 DNS 树、握手时序图、渲染流水线

## 开场（约 12 秒）
- 旁白：从输入网址到页面出现，中间发生了什么？每天打开网页都在经历这一切。我们分八步，把它从头到尾讲清楚。
- 字数：44 字
- 画面提示：第一期开场的浏览器加问号；问号散开，排成 1 到 8 的步骤条，顶部标签“8 步看懂一次访问”。

## 第 1 章 URL 解析（约 15 秒）
- 旁白：第一步，解析网址：拆出协议、域名、端口和路径；不是网址就交给搜索引擎。域名在 HSTS 名单里，HTTP 会被直接升级成 HTTPS。
- 字数：55 字
- 画面提示：`https://example.com:443/index.html` 被切成四块并分别标注；一个 http 字样被 HSTS 盾牌翻成 https。

## 第 2 章 缓存检查（约 13 秒）
- 旁白：第二步，查缓存。资源存过，且 Cache-Control 规定的有效期没过，就是命中强缓存，直接使用，不发请求。
- 字数：47 字
- 画面提示：浏览器旁边一个缓存抽屉，抽出一个带倒计时的文件，绿色对勾，标注“强缓存命中，不发请求”。

## 第 3 章 DNS 解析（约 19 秒）
- 旁白：第三步，DNS 解析，把域名换成 IP。先查浏览器缓存，再查系统缓存和 hosts 文件，都没有就问递归解析器。它依次询问根、顶级域和权威服务器，拿到 IP 返回并缓存。
- 字数：70 字
- 画面提示：左侧三层本地缓存依次闪过并标“未命中”；右侧 DNS 树：根 `.` → `com` → `example.com`，递归解析器沿树依次发问，最后带回 `203.0.113.10`（RFC 5737 文档专用示例地址）。

## 第 4 章 建立连接（约 22 秒）
- 旁白：第四步，建立连接。TCP 三次握手：客户端发 SYN，服务器回 SYN 加 ACK，客户端再回 ACK。HTTPS 还要做 TLS 握手，校验证书、协商出会话密钥。而 HTTP/3 改用基于 UDP 的 QUIC。
- 字数：83 字
- 画面提示：时序图，浏览器和服务器两条竖线，三条箭头依次标 SYN、SYN+ACK、ACK；随后一个锁图标出现，标注“证书校验、密钥协商”；角落一行小字“HTTP/3 = QUIC over UDP”。

## 第 5 章 发送请求（约 18 秒）
- 旁白：第五步，发送 HTTP 请求。请求行写着方法、路径和协议版本，比如 GET 首页；请求头带上 Host、Cookie，以及用于协商缓存的 If-None-Match。
- 字数：69 字
- 画面提示：沿用第一期的信封，上面依次亮起 `GET /index.html HTTP/1.1`、`Host`、`Cookie`、`If-None-Match`，飞向服务器。

## 第 6 章 服务器处理（约 20 秒）
- 旁白：第六步，服务器处理。如果用了 CDN，DNS 阶段就已把你指向就近的边缘节点，命中缓存直接返回；否则请求经负载均衡和反向代理到达应用服务器，读取静态文件或动态生成页面。
- 字数：75 字
- 画面提示：先出现一个 CDN 边缘节点，命中时信封直接从这里折返；未命中时信封再穿过负载均衡、反向代理两道门，落进源站服务器；沿用第一期的文件夹和齿轮两个图标。

## 第 7 章 返回响应（约 27 秒）
- 旁白：第七步，返回响应。200 表示成功，301 是永久重定向，404 是找不到，500 是服务器出错。资源没变就返回 304，浏览器用本地缓存，这是协商缓存。响应头还会带 Content-Type、Cache-Control 和 Set-Cookie。
- 字数：106 字
- 画面提示：响应包上依次翻牌：绿色 200、蓝色 301、橙色 404、红色 500；然后单独放大 304，一条箭头指回缓存抽屉；最后列出三个响应头。

## 第 8 章 浏览器渲染（约 22 秒）
- 旁白：第八步，渲染。HTML 解析成 DOM，CSS 解析成 CSSOM，合成渲染树，再经过布局、绘制和合成。普通脚本会阻塞解析，可用 defer 或 async。子资源会再发请求，连接可复用，最终四次挥手关闭。
- 字数：84 字
- 画面提示：渲染流水线横排五格：DOM、CSSOM、渲染树、布局、绘制/合成，依次点亮；一个 `<script>` 方块挡住流水线，加上 defer 标签后让开；结尾四条箭头示意挥手。

## 结尾：最后，串起来看一遍（约 26 秒）
- 旁白：最后，串起来看一遍：浏览器解析网址、检查缓存；未命中就做 DNS 解析拿到 IP；TCP 三次握手，HTTPS 再做 TLS 握手；然后发送 HTTP 请求，服务器处理后返回 200 或 304 等响应；浏览器再构建 DOM 和 CSSOM，经过布局、绘制、合成，展示页面。
- 字数：106 字
- 画面提示：8 步步骤条在屏幕左侧竖排，旁白讲到哪一步就点亮哪一步；最后整条变绿，标题打出“一次访问，八步完成”。
