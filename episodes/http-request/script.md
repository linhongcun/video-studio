# 脚本：《一次 HTTP 请求是如何完成的？》

- 总时长约 30 秒，5 段旁白，字数按汉字和英文字母/数字计（不含标点和空格）
- 字幕与旁白逐句对应；不讲 DNS/TCP/TLS

## 第 1 段：开场提问（约 4 秒）
- 旁白：输入网址，按下回车，背后发生了什么？
- 字数：15 字
- 画面提示：深色背景，浏览器窗口居中，地址栏逐字打出 `https://example.com`，回车键按下时闪一下青色光，画面中央浮出一个问号。

## 第 2 段：浏览器发送请求（约 7 秒）
- 旁白：浏览器发出一个 HTTP 请求：用 GET 方法，带上路径和请求头，像一封信飞向服务器。
- 字数：36 字
- 画面提示：浏览器左、服务器机柜右。浏览器里弹出一个信封形数据包，上面依次亮起三行标签：`GET`、`/index.html`、`Headers`。信封沿蓝色虚线飞向右边的服务器。

## 第 3 段：服务器处理（约 6 秒）
- 旁白：服务器收到请求，按路径找到页面，或者现场生成内容。
- 字数：22 字
- 画面提示：信封落进服务器，机柜指示灯依次闪烁；旁边出现两个小图标，左边是文件夹里抽出一个 HTML 文件，右边是齿轮转动生成文件，两者都汇到一个响应包里。

## 第 4 段：返回响应（约 7 秒）
- 旁白：接着服务器返回响应：状态码 200 OK 表示成功，后面跟着网页的 HTML。
- 字数：32 字
- 画面提示：响应包上先亮起绿色大字 `200 OK`，下面展开一小段 HTML 代码（`<html>…</html>`），然后沿青色虚线飞回左边的浏览器。

## 第 5 段：展示与收尾（约 6 秒）
- 旁白：浏览器解析 HTML，画出页面。一来一回，这就是请求与响应。
- 字数：25 字
- 画面提示：HTML 代码在浏览器里展开成标题、图片、按钮组成的网页；随后镜头拉远，浏览器和服务器之间两条箭头（请求向右、响应向左）循环一次，底部打出标题字“请求 — 响应”。

## 合计
- 旁白总字数：130 字
- 预计总时长：约 30 秒（4 + 7 + 6 + 7 + 6）
