# 第一期读法表（2026-10-14 补档，只改送给 TTS 的文字，字幕不动）

本期配音已按冰糖整期重配，并通过语音识别逐字比对（见 /workspace/knoll-audit-revoice/qa-report.md）。本表记录现行读法，供以后重配沿用。

- 英文缩写按字母一个个读：DNS、IP、TCP、UDP、TLS、HTTP、HTTPS、URL、CDN、DOM、CSSOM、HSTS、SYN、ACK、GET、HTML、CSS
- QUIC：作为单词读 quick，不按字母读
- HTTP/3：读「HTTP 三」；HTTP/1.1：读「HTTP 一点一」
- 状态码逐位念：304「三零四」、301「三零一」、404「四零四」、500「五零零」；200 按习惯念「二百」
- 空闲：kòng xián（已单独复查，识别为「空闲」）
- 读不准时改前后的说法，术语不删
- Cache-Control：第二步（cache-1）旁白先念中文「缓存控制头」再跟 Cache-Control，2026-10-14 因识别不准改的说法；字幕和标签保留 Cache-Control
