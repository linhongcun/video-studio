# 第十四期读法表（只改送给 TTS 的文字，字幕不动）

- B+ 树：配音文本写「B 加树」，B 按字母念；提防 TTS 漏掉「加」读成「B 树」，或读成「B 正树」「B plus 树」。配完用 large-v3 单独切出核对；念不准就改前后说法（先说「多层目录」），这个词不删
- 索引：suǒ yǐn
- 全表扫描：quán biǎo sǎo miáo
- 一行一行：yì háng yì háng（「行」读 háng，不读 xíng）；第一行、那一行：háng
- 目录：mù lù
- 翻过去：fān guò qù
- 占纸、占用：zhàn
- 一层套一层：tào
- 挑用哪一个：tiāo
- 直达：zhí dá
- 旁白不出现 MySQL、InnoDB、SQL 关键字；如后续要加，MySQL 按官方读法「My S Q L」（research Q2）
