# EP.15 pronunciation.md

| 词 | 读法 | 处理 |
|---|---|---|
| 事务 | shì wù | 和「事物」「实物」同音。第一次出现时说「就叫一笔事务」（第 3 章），之后都带「事务」上下文；字幕始终写「事务」 |
| 回滚 | huí gǔn | 「滚」要读第三声，不能读轻。第 5 章「这一步叫回滚。」单独合成、单独核对 |
| 提交 | tí jiāo | 旁白只说中文；COMMIT 只放文章，画面不出现 |
| 原子性 | yuán zǐ xìng | 风险低 |
| 倒放 | dào fàng | 「倒」读第四声 dào，不能读成 dǎo |
| 倒着撤回 | dào zhe | 同上，读 dào |
| ROLLBACK / ACID | 不念 | 只放文章，画面不出现 |
