## 一条主线与连续状态

01对应接口审查任务：开发者要求检查新增必填字段对旧请求的影响，首帧点名Agent Skills和具体问题。02与03是同一任务的两种独立起始配置，前者两份正文常驻，后者只提供候选名称/描述；不是同一会话把已读正文卸载。04按适用描述选中方法，泛描述的风险随第二句出现，不承诺确定性自动路由。05把所选入口指引交给当前任务，训练参数不改变。

06先给稀疏双路径总览。07参考规则沿读取路径进入右侧当前上下文，原有任务/方法保留。08脚本留在外部，通过宿主工具执行；旧定义、新定义、旧客户端请求三个输入接入工具。执行状态由等待→执行中→运行完成，结果小标记抵达右侧后才展开完整结果行，不把脚本源码整体灌入上下文，也不让Markdown自执行。06的静态总览样本不冒充多个有效动态阶段。

09依次出现变更、规则、工具结果，再合为本地审查结论。10复用同一SkillGraph给既有对象命名，不另开三张定义卡。11保留已读内容，解释发现索引也有开销、小包未必更省、保留/压缩依宿主且仍需维护和核验。12回应开头的方法包问题，品牌为IT小村·原创，无下期预告或文章引流。
