# 团队规则：旧客户端不改代码还能否发送原请求

本例只讨论同一请求端点的 JSON 对象字段。数据、端点和规则均为合成教学示例。

## R1 新增可选字段

若新字段不在 `required` 中，旧客户端省略它仍能通过本例的必填字段校验。

## R2 新增必填约束

新增字段或已有可选字段进入 `required` 后，旧客户端可能没有提供该字段。即使它只是“新增一个字段”，也可能破坏旧请求。

审查须分别给出两种证据：

- 契约级证据：新 `required` 集合相对旧集合增加了哪些字段。
- 请求级证据：指定旧请求是否缺少新必填字段。一个样例通过不能证明所有旧客户端都兼容。

## 范围

检查器不分析响应字段、类型收窄、枚举、格式、认证、默认值、状态码语义或服务实际行为。新增可选字段在本例通过，只能称“通过已检查的必填字段规则”，不能称“完全兼容”。
