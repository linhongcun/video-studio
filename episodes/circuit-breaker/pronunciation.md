# 第十二期读法表（只改送给 TTS 的文字，字幕不动）

- 熔断：róng duàn
- 降级：jiàng jí（「降」读 jiàng，不读 xiáng）
- 雪崩：xuě bēng
- 半开：bàn kāi
- 超时：chāo shí
- 跳闸：tiào zhá；合闸 / 合上闸：hé zhá
- 空气开关：kōng qì kāi guān
- 调用：diào yòng（「调」读 diào，不读 tiáo）；恢复调用同
- 卡住：qiǎ zhù（「卡」读 qiǎ）
- 拖慢 / 拖垮：tuō màn
- 一层层：yì céng céng
- 可有可无：kě yǒu kě wú
- 扛住：káng zhù
- 只扣一次：zhǐ kòu yí cì
- 幂等：mì děng
- bug：送 TTS 的文字改成「出故障了吗？」，字幕保留「这是出 bug 了吗？」（hook 第 3 句）
- 读不准就改前后的说法，术语不删

- 硬依赖 / 软依赖：只在文章里出现，旁白不读

- 到手价：dào shǒu jià
- 红包：hóng bāo；红包抵扣：hóng bāo dǐ kòu
- 优惠券：yōu huì quàn（「券」读 quàn，不读 juàn）
- 加购：jiā gòu
- 结算：jié suàn
- 搜索推荐：sōu suǒ tuī jiàn
- 大促：dà cù
- 自动降级 / 主动降级：zì dòng jiàng jí / zhǔ dòng jiàng jí

## 备用
- 若「调用」读成 tiáo：送 TTS 的文字前后改说法，或用同音「掉用」，字幕仍为「调用」
- 若「券」读成 juàn：送 TTS 的文字可写同音「劝」，字幕仍为「优惠券」（avalanche 第 1 句）
- 若「加购」不清：送 TTS 改「加进购物车」，字幕同步
