# 第十二期读法表（只改送给 TTS 的文字，字幕不动）

- 熔断：róng duàn
- 降级：jiàng jí（「降」读 jiàng，不读 xiáng）
- 雪崩：xuě bēng
- 半开：bàn kāi
- 超时：chāo shí
- 跳闸：tiào zhá；合闸 / 合上闸：hé zhá
- 空气开关：kōng qì kāi guān
- 调用：diào yòng（「调」读 diào，不读 tiáo）；恢复调用同
- 卡住：qiǎ zhù（「卡」读 qiǎ）
- 拖慢 / 拖垮：tuō màn
- 一层层：yì céng céng
- 可有可无：kě yǒu kě wú
- 扛住：káng zhù
- 只扣一次：zhǐ kòu yí cì
- 幂等：mì děng
- bug：送 TTS 的文字改成「出故障了吗？」，字幕保留「这是出 bug 了吗？」（hook 第 3 句）；「猜你喜欢」整体读，无特殊音
- 读不准就改前后的说法，术语不删

## 备用
- 若「调用」读成 tiáo：送 TTS 的文字可改「去叫它」类说法前后衔接，或用同音「掉用」，字幕仍为「调用」（breaker、half-open 两章）
- 若村长听出 recap「猜你喜欢」不清：送 TTS 改成「看到推荐那一栏一片空白」，字幕同步改；若「这就叫降级」不稳：改成「这种做法，就叫降级。」，术语保留
