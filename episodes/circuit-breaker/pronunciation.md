# 第十二期读法表（只改送给 TTS 的文字，字幕不动）

- 熔断：róng duàn
- 降级：jiàng jí（「降」读 jiàng，不读 xiáng）
- 雪崩：xuě bēng
- 半开：bàn kāi
- 超时：chāo shí
- 跳闸：tiào zhá；合闸 / 合上闸：hé zhá
- 空气开关：kōng qì kāi guān
- 调用：diào yòng（「调」读 diào，不读 tiáo）；恢复调用同
- 卡住：qiǎ zhù（「卡」读 qiǎ）
- 拖慢 / 拖垮：tuō màn
- 一层层：yì céng céng
- 可有可无：kě yǒu kě wú
- 扛住：káng zhù
- 只扣一次：zhǐ kòu yí cì
- 幂等：mì děng
- bug：送 TTS 的文字改成「出故障了吗？」，字幕保留「这是出 bug 了吗？」（hook 第 3 句）
- 读不准就改前后的说法，术语不删

- 积分：jī fēn；稍后到账：shāo hòu dào zhàng
- 硬依赖 / 软依赖：只在文章里出现，旁白不读

## 备用
- 若「调用」读成 tiáo：送 TTS 的文字前后改说法，或用同音「掉用」，字幕仍为「调用」（breaker、half-open 两章）
- 若「这就叫降级」不稳：改成「这种做法，就叫降级。」，术语保留
- 第 2 版已去掉「猜你喜欢」，原先那处风险不再存在
