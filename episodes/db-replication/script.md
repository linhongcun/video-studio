# EP.18《刚改的昵称，怎么又变回去了？》

- 主线：同一条用户7042昵称阿青→青禾，主库已提交，从库尚未应用；刷新读取旧值，不表示主库撤销修改。
- 画面术语只有主库、从库、主从延迟；各首次命名位于独立句首，对齐共享Rule的实测起音，显示至少63帧。
- 全屏深色canvas，讲实际记录与请求路径，不画物理服务器、电视、体育直播或假应用窗口，不出现性能实测数字。
- 新旧值持续可追踪；先主库，再从库，再写与返回，再读错去向，最后应用更改，避免一次堆满流程。
- 本例为单主库异步复制的教学结构，不推广为所有部署。写入成功不保证从库已接收或应用，接收与应用分开。
- 刚改后的查询修正限定为主库已提交、定向同一主库的新查询、无旧缓存；旧事务快照及故障切换等放文章。
- 示例昵称、用户编号均为教学设计，无固定延迟秒数；不声称等多久一定追上。
- 配音句级边界实测，不伪造ASR或逐字时间。公开依据见research.md。
