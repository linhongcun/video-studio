## 各章画面
1. **hook** 第 0 帧满屏封面画面：两行大字 + 大手机，昵称 旧昵称 → 新昵称 → 旧昵称；大字 0–36 完整、36–45 淡出，字幕 45 帧进
2. **tease** 手机上是旧昵称；右上赛场（主库）球已进网 + 盾牌 =「修改没丢」；右下电视球还在脚下 + 钟 =「慢半拍」
3. **live** ①电视在转播赛场，观众坐在前面 ②大赛场射门 → 信号线 → 电视晚 24 帧再进球（同一套图层推后）
4. **replica** ①大赛场（只有一名球员）②小赛场 + 电视 + 信号线；主库 / 从库 / 主从复制 三个标签同镜依次出
5. **split** ①赛场不变，观众挤在一台电视前 →「分到各台从库」左右两台电视亮起、观众走过去 ②观众再多、赛场照旧 → 读写分离；「备份」盾牌，「主库坏了」赛场关灯，中间一台电视绿框弹一下 = 顶上
6. **delay** ①左：邻居窗口 + 欢呼的观众；右：你家电视球还在脚下；顶上小赛场发出两条信号，邻居那条已到、你家这条圆点还在半路 ②赛场已进球、电视还在脚下、圆点在半路 → 复制延迟 ③手机写到赛场（橙线），再去电视读（青线）→ 昵称 新 → 旧
7. **async** ①赛场一进球马上冒「好了」，圆点才出发 → 异步复制 ②赛场关灯，圆点死在半路，顶上来的电视（橙框）球还在脚下 ③进球后信号线中途断（断裂图标），电视前的人永远看不到
8. **semisync** ①主库挂钟等 → 圆点到电视 → 电视冒「收到」→ 赛场才说「好了」②半同步复制；关灯了，电视有盾牌 = 改动已在手里 ③等太久钟变大 → 不等了直接「好了」，圆点还在路上 ④电视冒着「收到」可画面还是旧的，手机从它读 → 旧昵称
9. **fix** ①手机旧昵称 + 大「？」 ②电视变暗（别看转播），手机直连赛场（绿线）→ 新昵称
10. **recap** ①读写分离全景（赛场 + 三台电视 + 观众）②赛场 → 电视慢一点；手机从赛场读 → 新昵称
