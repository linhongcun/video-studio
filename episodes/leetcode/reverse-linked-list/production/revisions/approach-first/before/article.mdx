## 先弄懂要反转什么 {#problem}

LeetCode 206给出一个单向链表的头节点，要求反转链表，返回反转后的头节点。本片采用迭代解法，重点是：为什么修改`next`之前必须先保存原来的下一个节点。

一个节点有两个关键信息：一个值，以及引用下一个节点的`next`。单向链表只能沿`next`继续向后访问；`head`提供开始访问的入口，`None`表示没有节点。

教学输入是三个原节点：`1 → 2 → 3 → None`，`head`指向原节点1。目标是把连接改为`3 → 2 → 1 → None`，返回原节点3。图中三个节点的位置始终固定，因此目标也可以从右向左读。反转的是引用关系，节点的值不交换，程序也不创建替代节点。

例如，返回一个装着值3的新节点，再把原节点丢开，并不符合本片解法。正确结果必须仍然包含输入中的同一批节点，原节点1现在成为尾节点，它的`next`是`None`。

## 为什么必须先保存 {#save}

假设当前处理节点1。它的`next`原来指向节点2，我们希望把它改成指向空值，让节点1成为反转后链表的尾部。

一旦执行这个修改，`1.next`就不能再用来访问节点2。这个问题是**丢失继续访问原后半段的入口**，不能笼统说成节点2和3立即被销毁；对象是否仍然存在还取决于其他引用。

所以，修改之前要另存一个引用，指向原来的后继。它保存的是同一个节点的入口，不是复制节点或复制后半条链。

三个变量各有固定职责：

| 变量 | 中文角色 | 这一轮开始时指向什么 |
| --- | --- | --- |
| `prev` | 前驱指针 | 已经反转好的一段的头；最初为`None` |
| `cur` | 当前指针 | 这一轮要修改`next`的节点；最初为`head` |
| `nxt` | 临时指针 | 当前节点原来的后继，在修改前保存 |

这里“前驱”是处理过程中的角色：它所指节点应该成为当前节点反转后的下一个节点。`prev`初始为空，因此处理节点1时，`1.next`被正确改为空。

## 把三拍走完 {#reverse}

每轮都按同一个顺序进行：先保存原后继，再反转当前节点的`next`，最后依次把`prev`移到当前节点、把`cur`移到保存的原后继。

| 轮次 | 先保存原后继 | 再改变连接 | 最后移动并落定 |
| --- | --- | --- | --- |
| 第一轮 | `nxt`指向原节点2 | 原节点1的`next`改为`None` | `prev`指向1，`cur`指向2 |
| 第二轮 | `nxt`指向原节点3 | 原节点2的`next`改为原节点1 | `prev`指向2，`cur`指向3 |
| 第三轮 | `nxt`为`None` | 原节点3的`next`改为原节点2 | `prev`指向3，`cur`为`None` |

每次循环开始时，`prev`指向已处理节点组成的反向链；`cur`指向尚待处理部分的第一个节点。保存`cur.next`后，即使切断当前节点原来的连接，仍可以通过`nxt`找到剩余部分。把当前节点接到`prev`前面，已完成段就增加一个节点；依次更新两个变量后，同样的关系在下一轮继续成立。

因此，不能先反转`cur.next`再去保存它：那时读到的已经是新连接。也不能在反转前先把`cur`移走，否则处理对象就变了。四行更新的顺序具有实际含义。

图里的两处`None`都表示同一个空值。它们只是为了让向左的尾部连接和向右的未处理终点更容易读，不是两个节点。

## 停止、返回与完整程序 {#code}

`cur`变为`None`，说明所有原节点都处理完了。此时反向链的入口在`prev`，所以返回`prev`。

传入的`head`名称仍然引用原节点1；给`prev`或`cur`赋值不会自动把`head`改为新头。调用方应当接收返回值，例如将返回结果重新赋给自己的头变量。

下面是片尾同源的完整Python程序。LeetCode已预定义节点类型及其`next`属性，提交代码直接使用题目传入的节点，因此不需要自行创建`ListNode`，也不需要导入类型名称。

```python
class Solution:
    def reverseList(self, head):
        prev = None
        cur = head

        while cur:
            nxt = cur.next
            cur.next = prev
            prev = cur
            cur = nxt

        return prev
```

空链表时，`cur`一开始就是`None`，循环不执行，返回的`prev`也是`None`。单节点链表只执行一轮，节点的`next`仍为空，返回的还是它自身。

每个节点恰好处理一次，时间复杂度为`O(n)`；迭代过程只使用固定几个引用变量，额外空间为`O(1)`。这两个结论针对本片的迭代实现，不是递归实现的空间结论。

本片输入是合法的无环单链表。程序验证应同时检查返回顺序、节点身份未替换、节点值未变化、尾部为空以及结果无环，不能只比较打印出的数值。
