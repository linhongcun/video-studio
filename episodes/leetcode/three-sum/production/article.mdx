这篇文章面向会遍历数组、理解下标的读者。我们要解决的不是“找到一组和为零的三个数”，而是**找全所有不同的数值组合，而且不能使用同一个位置两次**。为什么排序能减少检查？为什么移动指针不会漏解？遇到重复值又该跳过谁？下面沿官方示例走完全程，再用一个明确标注的补例看去重。

## 题意与排序 {#question}

[LC.15 三数之和](https://leetcode.cn/problems/3sum/description/)给出整数数组，要求三个下标两两不同，总和为零，返回所有不重复的三元组。这里“重复”按数值组合判断；组合内部顺序和输出顺序都不重要。数值相同并不违反条件，只要来自不同位置即可。[^problem]

<SourceQuote sourceId="R1" supports="这条原文规定返回结果不能重复；关于如何去重的正确性由后文排序与扫描范围推导。" />

贯穿视频和本文的主例是官方示例 1：

~~~text
输入：[-1, 0, 1, 2, -1, -4]
输出：[[-1, -1, 2], [-1, 0, 1]]
~~~

如果直接枚举三个下标，需要检查平方再乘一层的组合数量。排序后则能利用单调性：**先固定最靠左的一个下标 i，只在它右侧用 L、R 选择另两个位置**。这样始终有 i < L < R，三个位置自然不同。排序会改变位置顺序，但保留每个元素和重复次数；题目只返回数值，不要求返回原下标，因此可以在排序后的数组上工作。

本期 Python 用 `sorted(nums)` 生成有序副本，不修改调用者的原数组。[^sorting]

<SourceQuote sourceId="R2" supports="Python官方文档说明sorted()构建一个新的有序列表；该引文仅支持实现语义，不为双指针算法作证明。" translation="译文：还有内置函数 sorted()，它从可迭代对象构建一个新的有序列表。" />

## 沿官方示例扫描 {#scan}

排序得到 `[-4, -1, -1, 0, 1, 2]`，下标从 0 开始。每轮固定 i，再让 L = i + 1、R = n - 1。以下两个排除依据在每一轮都适用。

**和偏小：排除当前左端。** 固定 -4，L 指向第一个 -1，R 指向 2，总和 -3。此时右端已经是当前候选区间内最大的数；保持这个 L，换任何更小的右数，总和都不可能升到零。所以可以排除这个 L，把 L 右移。

<Figure src="/video-studio/episodes/three-sum/article/01.svg" alt="排序数组负四、负一、负一、零、一、二；固定下标0负四，左指针下标1负一，右指针下标5二，总和负三。固定当前左指针时二已经最大，换更小右值也仍为负，所以左指针可右移。" caption="自制机制图：总和偏小时，排除的是“使用当前左端值的全部剩余配对”，而不是随意换一个数。" kind="diagram" />

固定 -4 的完整扫描如下。每次和都偏小，因此逐步移动 L：

| i 固定值 | L 的下标/值 | R 的下标/值 | 总和 | 动作 |
| --- | --- | --- | --- | --- |
| -4 | 1 / -1 | 5 / 2 | -3 | L → 2 |
| -4 | 2 / -1 | 5 / 2 | -3 | L → 3 |
| -4 | 3 / 0 | 5 / 2 | -2 | L → 4 |
| -4 | 4 / 1 | 5 / 2 | -1 | L → 5，相遇 |

接着固定下标 1 的 -1。L = 2，R = 5，得到 `-1 + (-1) + 2 = 0`，记录 `[-1,-1,2]`。命中后跳过左侧的当前值 -1 和右侧的当前值 2，L = 3、R = 4；再得到 `-1 + 0 + 1 = 0`，记录 `[-1,0,1]`。先右移 L 到下标 4，此时已经与 R 相遇，右侧循环不再移动，结束本轮。

下标 2 的固定值仍为 -1，属于已经做过的固定值，跳过。随后固定下标 3 的 0，L = 4、R = 5，总和 `0 + 1 + 2 = 3`。

**和偏大：排除当前右端。** 对当前 R = 5，左端 1 已经是剩余候选中最小的数；换成更大的左数，总和只会更大。因此这个 R 不可能配出零，可以把 R 左移。相遇后结束。本例 i 只需取到 n - 3，因为后面还要留下两个不同位置。两组答案至此全部找到。

## 去重为什么不漏解 {#dedup}

去重发生在两层：

1. **外层固定值重复就跳过。** 前一个相同固定值所在位置更靠左，它的右侧候选包含当前固定值右侧的全部候选，因此后一次固定相同数值不会产生新的数值组合。注意：只跳过重复的“固定值轮次”，不能事先把整个输入去重。
2. **命中后跳过左右两端的等值段。** 固定值确定时，左值一旦确定，能令总和为零的右值也唯一确定。刚记录过一组答案，再用同值的其他位置只能重复同一组合。跳到新值后继续搜索，才可能产生新答案。

用补充教学示例 `[-2,0,0,2,2]` 看第二层：固定 -2，先用下标 1 的 0 和下标 4 的 2 命中。代码将左侧两个 0 一并跳过，L 到下标 3；再跳过右侧 2，R 到下标 3，两端相遇。只输出一次 `[-2,0,2]`。这个补例不是官方示例 1，切换是为了放大“等值段”的实际动作。

## 边界、实现与代价 {#close}

官方示例 `[0,0,0]` 返回 `[[0,0,0]]`：三个零来自三个位置。输入 `[0,0,0,0]` 也只返回这一组，不能因为不允许重复答案就把三个零拒绝掉。官方示例 `[0,1,1]` 的唯一三数和是 2，返回空列表。

~~~python
class Solution:
    def threeSum(self, nums: list[int]) -> list[list[int]]:
        a, ans = sorted(nums), []
        for i in range(len(a) - 2):
            if a[i] > 0:
                break
            if i > 0 and a[i] == a[i - 1]:
                continue
            l, r = i + 1, len(a) - 1
            while l < r:
                total = a[i] + a[l] + a[r]
                if total < 0:
                    l += 1
                elif total > 0:
                        r -= 1
                else:
                    ans.append([a[i], a[l], a[r]])
                    left, right = a[l], a[r]
                    while l < r and a[l] == left:
                        l += 1
                    while l < r and a[r] == right:
                        r -= 1
        return ans
~~~

`a[i] > 0` 时，后面两个数也一定为正，不可能再凑零，可以直接停止外层循环。这个提前停止条件不能写成大于等于零，否则会漏掉三个零。所有移动都检查 `l < r`，不允许同一位置被使用两次。

排序时间 O(n log n)；每个固定值下，L 只增、R 只减，合计 O(n) 步，外层 O(n) 轮，因此总时间 O(n²)。本实现复制有序数组，并考虑 Python 排序工作空间，**除输出以外额外空间 O(n)**；不是 O(1)。若有 k 组答案，结果本身还需 O(k) 空间。

可直接运行的 `solution.py`、独立暴力枚举与轨迹测试在本期制作源码中。测试覆盖官方例子、全零、重复固定值、重复左右值、无解以及小值域的穷举数组；程序一致性并不替代视频里实际动作和配音的复核。

读完后应能解释：和偏小或偏大时，每次移动都排除一个不可能成功的端点；命中后跳过等值端点，以及跳过重复固定值，避免再次输出相同的数值组合。**有序性保证不漏解，分层去重保证不重复。**
