# LC.15 调研与推导
2026-11-15 直接读取官方题面、GraphQL 与 Python 官方排序文档。逐字证据见 research/source-evidence.json；没有凭记忆替代本次访问。
- LeetCode 题名 3Sum，中文三数之和；三个下标两两不同，总和为零，结果按数值组合去重。官方示例1 [-1,0,1,2,-1,-4]，结果 [-1,-1,2]、[-1,0,1]；另两个示例 [0,1,1] 与 [0,0,0]。
- 选题在官方 Hot 100 中，热门集合依据，不声称实时排行。
- 排除依据为本期推导：固定 a[i]。和小于零时，对固定左端 l，任意 k<=r 都不大于当前总和，所以 l 可被排除。和大于零时，对固定右端 r，任意 k>=l 都不小于当前总和，所以 r 可被排除。
- 命中后若左值不变，右值由方程唯一确定；跳过左右等值仅去掉重复组合。固定值重复时，前一次相同固定值拥有其右方候选的超集，因此可以跳过。
- sorted(nums) 返回新列表；本期实现按复制排序数组与 Python 排序工作空间计除输出 O(n)，不宣称 O(1)。指针扫描总 O(n²)，排序 O(n log n) 被其支配。
- solution.py 与独立组合枚举 oracle、教学 trace 做穷举核对；动画读取 trace，不手填答案。
