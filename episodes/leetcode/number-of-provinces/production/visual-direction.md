# 视觉主线：城市关系与归属记录各自清楚

本期先使用原题的城市和相连关系建立问题。城市图不是抽象数字阵列的装饰底图：AB、BC两段线要实际演出A与C的间接连通，DE单独一组，F在全片都可被定位并计入结果。城市图中的位置不代表真实地理；不存在的AC边在主例中始终不能出现。

原相连关系用实线，归属记录在独立面板使用虚线。若C的记录指向A，不得把这条箭头画成原图中的AC直接关系。画面随查找逐段高亮归属，沿箭头抵达自指根后才提交查找结果；合并时先找两根，再接根，最后计数减一，不以“两个圆点颜色同了”代替动作。

## 推导与命名

01–02完整交代输入、目标、直接与间接连通、孤城和输出3。03从只求分组的需求推出查询与合并；04才给组一个代表；05演出上级记录和根的意义，明确虚线不是新连接；06在跨组找根、接根动作可理解后，再于第二句完整句首cue显示并查集。不能在题意首屏或未经推导的标题中提前宣布方法。

前半段可使用真实trace快照作为概念示意，但标示局部演示；第07镜口头与图像都明确回到六独立组，开始主例的真实上三角遍历。所有parent、size、count、find路径和合并次序消费research/trace.json，不在TSX另写解题器。

## 三个应当看清的过程

- AB：分别找到A和B的根，B根接A根，6→5；查B能沿记录找到A。
- BC：B先沿记录到A，C是自己的根，接C根到A根，5→4；此时原图AC仍无边。
- DE与孤F：接E根到D根，4→3；扫完仍保留F自指，返回ABC、DE、F三组。

10单独标“补例：新增AC，重新扫描”。从六独立组开始，AB与AC后已经4组；随后BC同根跳过，4保持4。本镜止于局部，并标DE尚未处理；不把4说成最终答案，不在最后无声完成DE又称仍4。11口头与图像一同回到无AC主例矩阵。
