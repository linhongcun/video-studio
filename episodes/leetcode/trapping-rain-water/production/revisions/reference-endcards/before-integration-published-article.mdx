## 给了什么，要返回什么 {#problem}

LeetCode 42 给出一列非负整数，每个整数是相应柱子的高度，每根柱子的宽度都是1。雨水会从敞开的左右两边流走，题目要求把最后留下的单位水量相加，返回一个整数。这里不选择两根柱子求容器面积；所有凹处都要算，柱子占住的体积不能算成水。

<SourceQuote sourceId="A1" supports="柱高非负、每根柱宽为1，目标是计算雨后留下的水量。" translation="给定 n 个非负整数表示的地形图，其中每根柱子的宽度为1，计算下雨后能留下多少水。" />

视频的自选教学示例为 `[3,0,2,0,4,0,1]`。左盆能留下7格水，右侧小凹处留下1格，总共返回8。每个蓝色单位格都在相应灰色柱子的上方；高2的第三根柱子上只有1格水，柱体里没有水。

## 先从一列推导水位 {#derive}

看第四列：左边有高3的阻挡，右边有高4的阻挡。水位一旦超过3，就从左边流走，因此较矮的阻挡决定该列最终水位3。

不能只看紧挨着的柱子。第三列高2的矮柱可以整个被淹过，更远的高3柱仍能挡水。也不能把全局最高4当作所有凹处的水位：第六列右侧只有高1的柱子，那个小凹处只能留下水位1。

对每一列，我们需要知道左右各自最高的柱子。如果每次都重新向两边寻找，会重复经过相同的位置。从左向右走时，只要记住到目前见过的最高高度，就能为每列保存左侧答案；反向再走一遍，得到右侧答案。这样的两组记录分别叫前缀最高值和后缀最高值。

## 定义与计算 {#scan}

本片两组最高值**都包含当前柱**：

- `left[i]` 是 `height[0:i+1]` 的最高值。
- `right[i]` 是 `height[i:n]` 的最高值。
- 水位 `level = min(left[i], right[i])`。
- 水深 `depth = level - height[i]`。

由于两组最高值都不低于当前柱，水深不会为负；无需额外用0截断。第一列的左记录恰是它自己，最后一列的右记录也是自己，水深自然为0。物理含义是边缘有一侧敞开，不能留水；不能因为另一侧有高柱就把水悬空填上去。

水位与水深不同：第三列水位3、柱高2，水深只有1。各列宽度为1，因此该列的单位水量就等于水深。

## 完整Python程序 {#code}

下面程序与片尾5秒暂停卡、真实执行trace读取的 `solution.py` 完全同源。两个数组先准备好，再按顺序累加水深，不修改输入。

```python
class Solution:
    def trap(self, height: list[int]) -> int:
        n = len(height)
        left = [0] * n
        right = [0] * n
        highest = 0
        for i in range(n):
            highest = max(highest, height[i])
            left[i] = highest
        highest = 0
        for i in range(n - 1, -1, -1):
            highest = max(highest, height[i])
            right[i] = highest
        total = 0
        for i in range(n):
            level = min(left[i], right[i])
            depth = level - height[i]
            total += depth
        return total
```

三次线性扫描，总时间为 `O(n)`；两个长度为 `n` 的数组占用 `O(n)` 辅助空间。官方输入长度至少1；该实现对空列表也自然返回0，这只是额外稳健性，不改变题目约束。

两侧最高值的较小值既是上界，也确实能达到：若水位超过其中更低的一侧，会从那一侧流走；不超过两侧最高值时，两边都有足够高的阻挡。两侧之间可能存在矮柱，它们占住的部分由减去本列柱高去除，不会阻止其上方空格存水。每列只算一次，相加便得到整排水量。
