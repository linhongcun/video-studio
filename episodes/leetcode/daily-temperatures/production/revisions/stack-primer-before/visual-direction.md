# LC.739 视觉导演说明

主对象是同一条按日期排列的气温线，x轴是第几天，y轴是气温高度；较暖由真实高度关系表达，等待天数由两天之间的水平跨度表达。图从28为显示基准起画并显式标记，不声称绝对零点或真实天气单位。原输入不排序、不移动；答案始终在原日期下方落定。

颜色语义保持稳定：蓝色是给定气温与未解决日期标记，金色是当前比较，青色是已写回答案与等待跨度，灰色是尚未处理或辅助说明。气温线保留连续性；较凉只是不能解决旧日子，不代表日期被删除。

四章通过左上简短标题提供当前位置，没有与讲解无关的进度条。01–02题意；03–05从重复查找到温度有序，05第二句才显示单调栈；06显式重置同一输入正式执行；06–10依次处理到末尾；11明确另一组相等输入并重置；12返回主例；13成本；14写回与暂停代码卡。

辅助待解决区位于气温图下方，用“第几天·气温”标记并以细线连接原日期。加入时标记从原日期移动到辅助区；移出时标记回到原日期答案位置，随后答案出现。保留原气温点是为了读输入，移动的是它的待解决下标标记，不能误看成修改天气。末尾先检查的方向固定，不在镜间翻转。

数据唯一来自research/trace.json，生成器sys.settrace运行solution.py，不在Main.tsx另解题。data.ts只给真实事件id安排句级动作；比较、移出、写回、加入按trace顺序显示，不能只展示最终结果。首次空栈明确“无旧天可比较”，首次较凉明确停止原因，相等不移出，最后未解决保留0。
