# LC.347 前K个高频元素：为什么把最少的放在堆顶？

唯一承诺：由“只要前k个”推导保留候选与删除最少者，再用同一组频次建立小顶堆父子关系，完整看到加入、上移、删除、补位和下移，最终返回出现最多的k个不同数字。

画面约定：全屏深色canvas，沿共享LeetCode深蓝/暖金/青色模板；输入数组、计数表和堆直接承担讲解，不模拟设备、不用比喻。节点一律标“数字×次数”，所有比较先看次数。父子局部有序不等于全局排序；左孩子无须比右孩子小。示例数组及k完整显示，返回值是不同数字，不是次数或下标。

输入：nums=[1,1,1,2,2,3,4,4,4,4,5,5,5,5,5,6]，k=3。处理计数表时沿首次出现顺序1→2→3→4→5→6。正式过程从06镜空堆开始；03–05标规则/结构示意，不冒充一次已经完成的执行。每个候选先push，超过k再pop，因此有临时k+1节点；不得把容量k写成全过程最大节点数。
