# EP.60 · 分镜设计（审读稿，未配音）

镜头顺序对应 script.md 的 9 个标题；每镜两句旁白。实际帧长、音频 cue 和字幕退场帧待独立审读后配音再定。

## 数据映射与视觉

- 字符串按下标逐格显示在同一行，每格一个括号，格下标注“第几个”；括号按类型着色：圆括号蓝、方括号紫、花括号粉。配对成功的两格变青色并打勾，失败格变红。
- 栈画在字符行右侧，自底向上叠放，顶部标“栈顶”；入栈时字符格从行内滑到栈顶位置，出栈时栈顶上浮淡出。
- 视频中的所有教学字符串区域均显式标注“示例”。主例固定为 "{[()]}()"，提问例为官方示例 5 "([)]"，失败例为 "())" 与 "(()"。
- 使用共享深蓝、暖金、青色 LeetCode palette；调用 episodes/_shared/leetcode-video/Frame.tsx 中的 LeetcodeBackdrop、LeetcodeHeader。无浏览器外壳和装饰进度条。

## 逐镜动作

1. **01 input：** 三类括号成对展示；第二句起依次出现 "()[]{}" 有效、"(]" 类型不同、"([)]" 顺序错误。
2. **02 question：** "([)]" 的前两个左括号标为“未配对”，指针停在第 3 个字符右圆括号并提问；第二句高亮最近未配对的 '['，标出类型不同、无效。本镜不出现栈。
3. **03 method：** 同一例子重新把两个左括号收进栈，强调最近放入的在最上面；第二句命名“栈 · 后进先出”，列出两条操作。
4. **04 begin：** 换到有效主例，前三个左括号依次入栈；第二句高亮栈顶 '('。
5. **05 pop：** 第 4 个字符 ')' 与栈顶配对弹出；第二句高亮新的栈顶 '['。
6. **06 unwind：** 第 5 个字符 ']' 配对弹出；第二句第 6 个字符 '}' 配对弹出，栈清空。
7. **07 finish：** 第 7 个 '(' 入栈并被第 8 个 ')' 弹出；第二句读完，显示“栈为空 → 有效”。
8. **08 fail：** 左侧 "())" 在第三个字符时栈空无效；第二句右侧 "(()" 读完后栈内剩 '(' 无效。
9. **09 close：** 主例最终状态与三条规则；第二句显示字典映射与线性时间、空间。随后 5 秒完整 Python 代码卡、5 秒资料页。
