# EP.60 · LC.20《有效的括号》脚本 v0.2

已按独立逻辑审读（98638c1f）修订：例子切换说明、字符序数、01 前提、02 指代、09 动词。每镜两句旁白，镜头标题与旁白行兼容 episodes/_shared/voice/prep.py；当前无音轨或实际帧时序。100–140 秒仅为容量参考，不以加快语速达成。

### 01 input
旁白：题目给出一个只包含圆括号、方括号和花括号的字符串，判断它是否有效。有效要求每个左括号都被同类型的右括号闭合，每个右括号都有对应的左括号，而且闭合的顺序必须正确。

### 02 question
旁白：看这个例子：读到第一个右圆括号时，前面有左圆括号和左方括号，它该和谁配对？左方括号是最近一个还没配对的左括号，它必须先闭合，外层的左圆括号才能闭合，所以右圆括号只能和左方括号比较，类型不同，字符串无效。

### 03 method
旁白：规则由此清楚了：只要记住所有还没配对的左括号，每遇到右括号，就取出最近放进去的那个来比较。后放进去的先取出来，正是栈的后进先出，所以左括号入栈，右括号与栈顶比较。

### 04 begin
旁白：换一个有效的例子从头走一遍：前三个字符都是左括号，依次压入栈中。此时栈顶是最里层的左圆括号，它就是下一个右括号必须配对的对象。

### 05 pop
旁白：第四个字符是右圆括号，栈顶正好是左圆括号，类型相同，配对成功，栈顶弹出。弹出以后，栈顶回到左方括号，说明最里层已经闭合，接下来轮到它。

### 06 unwind
旁白：第五个字符是右方括号，与栈顶的左方括号同类，配对后弹出。第六个字符是右花括号，与栈顶的左花括号配对弹出，三层嵌套从里到外依次闭合，栈恰好清空。

### 07 finish
旁白：第七个字符是新的左圆括号，入栈后紧跟着的第八个字符右圆括号把它弹出。字符串读完，栈里没有剩余的左括号，所有括号都已配对，返回有效。

### 08 fail
旁白：再看两种失败：如果右括号到来时栈已经是空的，说明没有左括号可以配对，直接无效。如果字符串读完栈里还剩左括号，说明它们始终没有闭合，同样无效。

### 09 close
旁白：归纳成三条：左括号入栈；遇到右括号，栈为空或栈顶类型不同就无效，相同就弹出；最后栈为空才有效。用字典把右括号映射到对应的左括号，每个字符只处理一次，时间随长度线性增长，栈最多装下全部左括号，额外空间同样线性。
