# EP.62 · LC.207 课程表
v0.1；九镜。主线用四门课的教学示例：先入度统计与无环主例，第六镜明确切换成环补例，第八镜官方边界与孤立课。句号只作句界，课程按编号口播，字幕与画面状态对应。

### 01 input
旁白：一共四门课，编号从零到三；先修表的每一项里，前一门是目标课程，后一门是它必须先学的先修课，问题只有一个：能不能把全部课程学完。把每一项画成一条从先修课指向目标课的箭头，这张表就变成一张课程先修图，能不能学完，就看这张图里有没有转圈等待的环。

### 02 graph
旁白：四项先修关系全部画成箭头，零号指向一号和二号，一号和二号都指向三号，这张图的样子就固定了。如果顺着箭头能走一圈回到出发的课程，就是谁先学谁后学的死循环，谁也无法开始。

### 03 indegree
旁白：先看哪门课现在就能学：没有剩余先修要求的课，也就是没有箭头指向它的课。给每门课数一下还有几条边指进来，这个数字叫入度，入度为零的课放进队列，就是当前能上的课。

### 04 learn
旁白：零号课没有任何先修要求，先进队列；学完零号，一号和二号的等待同时清零，先后进入队列。先学一号，三号的等待从二减到一；再学二号，三号的等待清零进队列，学完三号，四门课全部完成。

### 05 why
旁白：判断依据很直接：学完一门课，就把它指出去的边删掉，后续课程的入度减一。队列里始终是当前就能学的课，队列不空，进度就一直在推进；学完的门数等于课程总数，就能学成。

### 06 cycle
旁白：现在把最后一项换掉，让三号反过来先修一号：一号等三号，三号等二号，二号等一号，三门课互相等。入度统计出来，还是只有零号没有先修要求；学完零号，一号的等待仍剩一门，队列空了。

### 07 blocked
旁白：队列空了，说明剩下的每门课都还有没解除的先修；从任意一门沿先修边走，课程有限，迟早回到走过的课，这就是环。所以不是排课顺序选错了，而是这组先修要求根本无解，返回不能学成。

### 08 edge
旁白：再看边界：官方第二个示例只有两门课，却互相先修，同样是一个环，不能学成。先修表为空时每门课入度都是零，全部能学；不参与任何先修关系的孤立课程也一样，直接进队列。

### 09 close
旁白：先修关系画成边，没有先修要求的课先进队列；每学完一门就删掉它指出的边，入度减到零的课继续进队列。这套做法叫拓扑排序；每门课只进出队列一次，每条边也只删一次，时间和额外空间都是线性级，完整代码请暂停阅读。
