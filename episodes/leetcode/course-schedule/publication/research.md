# LC.207 调研与推导
2026-11-15 直接读取官方题面、GraphQL 与英文 Wikipedia 拓扑排序条目。逐字证据见 research/source-evidence.json；没有凭记忆替代本次访问。
- LeetCode 题名 Course Schedule，中文课程表；numCourses 门课编号 0 到 n-1，prerequisites[i]=[ai,bi] 表示学 ai 前必须先学 bi；返回能否完成全部课程的布尔值。官方示例 [[1,0]] 为 true，[[1,0],[0,1]] 为 false。
- 选题在官方 Hot 100 中，热门集合依据，不声称实时排行。
- 视频主线用四门课教学示例 [[1,0],[2,0],[3,1],[3,2]]：边 0→1、0→2、1→3、2→3，可全部学完；补例把最后一项改成 [1,3]：0→1、1→2、2→3、3→1，学完 0 后剩余 1、2、3 互相等待，判定不能学成。
- 判定依据：Kahn 过程每次只学入度为零的课并删掉它的出边；无环有限图至少存在一个入度为零的点，队列空且仍有未学课程时，剩余课程沿先修边必回到走过的课，即存在环。与 Wikipedia 条目伪代码「图仍有边则返回至少一个环」一致。
- solution.py 用列表加头指针作队列，不新增第三方依赖；每课入队出队各一次、每边删一次，时间与额外空间均为 O(n+e)。
- solution.py 与 DFS 三色判环 oracle、教学 trace 做官方示例、边界与小规模穷举核对；动画读取 trace，不手填答案。
