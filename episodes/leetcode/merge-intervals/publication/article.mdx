## 题目与区间 {#question}

题目给出若干个 <code>[start,end]</code> 闭区间，每段的两个端点都包含在内，输入顺序可以任意。目标是把重叠的区间合并，返回一组互不重叠、覆盖范围与原输入完全相同的区间。它不是要求把每个端点都保留成一行，也不是要求返回某种固定的内部遍历顺序。

题面明确把端点相接视为重叠：<code>[1,4]</code> 和 <code>[4,5]</code> 应合并。[^problem]

<SourceQuote sourceId="R1" supports="官方示例明确端点相接仍算重叠；该原句只支持题意，不证明排序扫描算法正确。" />

本文使用同一组教学输入：

~~~text
[[8,10],[1,4],[2,3],[3,5],[5,6],[12,14]]
~~~

输入位置只用于追踪对象：I0=[8,10]、I1=[1,4]、I2=[2,3]、I3=[3,5]、I4=[5,6]、I5=[12,14]。这些标识不是题目要求返回的下标。不同段必须映射到同一条数轴，才看得出输入顺序、区间位置和算法状态之间的关系。

## 为什么先按起点排序？ {#sorting}

如果直接按输入顺序扫描，看到 I0=[8,10] 后不能知道它是否已经可以结束：后面可能还有起点更早、能与它相连的区间。乱序把“现在是否还有更早的段会出现”留成未知。

按起点排序后，处理顺序变为 I1=[1,4]、I2=[2,3]、I3=[3,5]、I4=[5,6]、I0=[8,10]、I5=[12,14]。从任意位置向后看，新的起点都不会小于已经处理的起点。于是只需维护当前合并段，不需要回头寻找更早的区间。

Python 的 <code>sorted()</code> 返回一个新的排序列表。[^sorted]

<SourceQuote sourceId="R2" supports="Python官方文档说明 sorted() 返回新的排序列表；此引文不证明区间合并算法。" translation="译文：迭代对象中的元素会返回一个新的排序列表。" />

本实现使用 <code>key</code> 按每段起点取排序键，并在新列表中处理，不改写传入的 <code>intervals</code>。

## 当前段怎样改变？ {#scan}

从排序后的第一段 [1,4] 开始作为当前段。随后逐个处理下一区间：

1. I2=[2,3] 的起点 2 不超过当前终点 4，两段连在一起；新终点是 max(4,3)=4，所以嵌套区间不会把当前终点缩短。
2. I3=[3,5] 的起点仍不超过 4；max(4,5)=5，当前段延长为 [1,5]。
3. I4=[5,6] 的起点恰好等于当前终点。官方题目将这种端点相接视为重叠，因此继续合并，当前段变为 [1,6]。
4. I0=[8,10] 的起点 8 大于当前终点 6，数轴上有空隙；输出 [1,6] 并以 [8,10] 开始新段。
5. I5=[12,14] 同样与 [8,10] 分离，最终结果是 <code>[[1,6],[8,10],[12,14]]</code>。

## 为什么可以在空隙处结束？

扫描开始时，结果由两部分构成：已经确定结束的区间，以及最后一个仍在扩展的当前区间。保持以下不变量：

- 已完成区间互不重叠，且恰好覆盖已处理完的较早连通部分。
- 当前区间恰好覆盖最后一个连通部分；它的终点是这一部分所有输入区间终点的最大值。

对当前段 [L,R] 和排序后的下一段 [s,e]，若 `s <= R`，它与当前段重叠或端点相接，合并范围只能是 [L,max(R,e)]。若 s > R，存在无法跨越的空隙；所有后续区间的起点都不小于 s，因此没有后续区间能再连接到 [L,R]。此时输出当前段是安全的。每个输入区间只会进入一个连通分量，故结果既不遗漏覆盖，也不会跨过空隙。

## 完整 Python 程序 {#close}

~~~python
class Solution:
    def merge(self, intervals: list[list[int]]) -> list[list[int]]:
        if not intervals:
            return []

        ordered = sorted(intervals, key=lambda interval: interval[0])
        merged = []

        for start, end in ordered:
            if merged and start <= merged[-1][1]:
                merged[-1][1] = max(merged[-1][1], end)
            else:
                merged.append([start, end])

        return merged
~~~

题目约束保证至少有一个区间；空列表分支只是防御性处理。结果中的每个新区间都是单独创建的列表，合并时只改结果，不会改写输入区间。

排序耗时 O(n log n)，随后扫描每个区间一次，耗时 O(n)。排序副本和结果均可能随输入规模增长，故按这份实现计额外空间为 O(n)（含返回结果）。

## 小结

先按起点排序，才能从左到右判断当前区间。下一段起点不超过当前终点，就合并并保留较大的终点；出现空隙时，后续起点不会小于空隙处的起点，而该起点已大于当前终点，因此当前区间可以结束，最终覆盖范围不变。
