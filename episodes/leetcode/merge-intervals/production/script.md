# EP.59 · LC.56《合并区间》脚本 v0.2

### 01 input
旁白：先看输入的第一项，八和十这两个端点标到同一条数轴上，而且都包含在区间内。题目要求合并重叠区间，返回的区间彼此不重叠，覆盖范围与原输入完全一致。

### 02 touching
旁白：同一组输入里，三到五和五到六在五这个端点相接。因为两端都包含，只有这一点相接也要合并，当前范围会延到六。

### 03 order
旁白：输入顺序是乱的，处理到八到十后，后面仍可能出现起点更早的区间。按起点排好后，后面的起点都不会比前面小，才能从左向右判断。

### 04 begin
旁白：排序后，六段依次是：一到四、二到三、三到五、五到六、八到十、十二到十四。第一段起点最早，所以从一到四建立当前区间。

### 05 nested
旁白：下一段二到三完全落在一到四里面，仍然与当前段重叠。合并后要保留较大的终点四，不能被里面较短的区间缩回三。

### 06 overlap
旁白：三到五的起点三不超过当前终点四，所以仍然相连。把终点扩展到较大的五，当前段变成一到五。

### 07 touching
旁白：五到六的起点正好等于当前终点五，两段在端点相接。端点包含在内，仍须合并，当前段延长为一到六。

### 08 gap
旁白：八到十的起点八大于当前终点六，中间出现空隙。按起点排好的后续起点不会小于八，而八已经大于六，所以更后面的段也接不回来；把一到六写入结果，从八到十开始新段。

### 09 gap
旁白：十二到十四的起点十二大于当前终点十，两段隔着空隙，八到十因此独立成段。已经没有下一段了，扫描结束时再把当前的十二到十四写入结果。

### 10 close
旁白：归纳成两条规则：起点不超过当前终点就合并并保留较大终点；起点更大就有空隙、当前段结束，这就是排序扫描。本例得到三段：一到六、八到十、十二到十四；程序用新排序列表、不改原输入，主要时间花在排序，随后扫描和额外空间都随区间数线性增长。
