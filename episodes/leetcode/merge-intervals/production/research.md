# EP.59 · LC.56《合并区间》调研

核验日期：2026-11-14（北京时间）。本记录只覆盖官方题意、官方 Hot 100 题单归属与 Python sorted() 的返回语义；没有将镜像题解或内部手稿当作来源。

## 问题与适用范围

LeetCode 官方题面把输入定义为区间数组 intervals[i] = [start_i, end_i]，要求合并所有重叠区间，返回不重叠且恰好覆盖全部输入区间的数组。约束为至少一个区间，且每个区间满足 start <= end；空数组处理是实现的防御分支，不是题目要求。示例明确端点相接也算重叠，因此题解按两端包含的闭区间理解。

端点语义由官方示例 2、3 明确：[1,4] 与 [4,5]、[1,4] 与 [4,7] 均视为重叠。故扫描条件为 next_start <= current_end，不能误写成严格小于。

## 解法依据

任意输入顺序下，当前区间后仍可能出现更早的起点，单看当前项不能判定接下来是否连通。按起点排序后，后续起点单调不减：

1. 用第一个区间建立当前合并段。
2. 若下一段起点 <= 当前终点，两段重叠或相接，合并为 [current_start, max(current_end, next_end)]。取 max 保证嵌套区间不会缩短终点。
3. 若下一段起点 > 当前终点，已有空隙；由于余下起点只会更大，后续区间不可能再连接当前段，可输出它并开启新区间。

因此一次排序后只需从左到右扫描。排序耗时 O(n log n)，扫描 O(n)。本期实现用 sorted() 创建排序列表并建立独立结果，额外空间按实际代码为 O(n)（含结果）。

## 贯穿样例与轨迹

教学样例（不是官方示例）：
[[8,10],[1,4],[2,3],[3,5],[5,6],[12,14]]。

输入身份与排序后身份必须保持对应：I0=[8,10]、I1=[1,4]、I2=[2,3]、I3=[3,5]、I4=[5,6]、I5=[12,14]；排序后为 I1、I2、I3、I4、I0、I5。逐步结果应为 [1,4]、嵌套后仍为 [1,4]、扩展为 [1,5]、端点相接后为 [1,6]，再分别断开 [8,10] 与 [12,14]。轨迹由 merge_trace.py 运行扫描生成；每事件的完成段与当前段均由独立连通分量 oracle 核验。
