- **原题场景直接参与推理（L041 / L058）**：
  - 第 01 镜先给出带显式行列编号 `r=0..2, c=0..3` 的整数矩阵 `0/1/2`，随后同一网格逐格平滑变形为真实橘子箱插画：
    - `0` 空位：凹陷深色虚线槽 + 柔和 `0` 印记
    - `1` 新鲜橘子：饱满暖橙色矢量果体（双层高光 + 翠绿叶片 + 果蒂）
    - `2` 腐烂橘子：暗紫褐/枯橄榄斑点果体 + 枯叶 + 清晰腐烂时刻角标（`T=0 / T=1 / T=2 / T=3`）
- **比前作更进一步的动效与可读性**：
  1. **腐烂波纹与传播弧线**：当某个烂橘子向四邻扩散时，当前源格亮起暖金光环，四向检查箭头按真实轨迹方向伸展——感染新鲜橘子用亮青/橙光脉冲推动果体平滑变色并弹出 `+1` 时刻徽章；越界止于网格外框并显示淡红短止线「越界跳过」（L045）；遇空位止于凹槽边并显示「空位跳过」；遇已变 `2` 橘子亮温和蓝紫弧线「已为2跳过」。
  2. **分层队列可视化（核心记忆点）**：画布底部/右侧固定持久队列条，使用暖金括号明确框出「本分钟当前层（`len(q)`）」，新传染入队的橘子从右侧滑入「下一层」青色区，观众一眼看懂为什么每轮 `for _ in range(len(queue))` 恰好等于 1 分钟。
  3. **双源错算对比（第 02 镜）**：同一 3×4 橘子箱上先用半透明路径标出只从 `(0,0)` 算到 `(2,1)` 需要 3 步，随即在 `(2,2)` 点亮 1 步直接箭头的鲜明冲突，视觉直击「为什么必须同时入队」。
  4. **严格句窗驱动（L074）与状态守卫（L010 / L073）**：所有事件严格按本句 `cueFrames` 窗口推进，标题和底部状态条全部从当前事件推导，杜绝提前剧透或静止停滞；不使用任何装饰进度条（L018）。
