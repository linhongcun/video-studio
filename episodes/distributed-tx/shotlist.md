## 各章画面
1. **hook** ①第 0 帧封面大字「两个库」/「怎么一起成功或一起失败？」→ 手机成功页 + 硬币 → 货架满着 + 红叉账本 ②两个数据库：一个绿勾、一个红叉 + 火花
2. **signal** ①两个库 + 问号 + 绿牌 ②库变红站（账本）、蓝站（货架）——驿站只在此后出现
3. **local** ①单库整页擦掉 → 红站蓝站，红站擦自己的，蓝站货架打红叉 ②中间问号：得有人统一指挥
4. **prepare** ①对讲机调度员出场 ②问号 → 红站铅笔单 → 蓝站货进待出库格子锁住
5. **commit** ①绿牌 → 盖章；红牌 → 全部擦掉 ②铅笔单 → 盖章单，两阶段提交
6. **stuck** 对讲机红叉，铅笔单和锁着的货不动，沙漏干等（push-in）
7. **tcc** ①锁住的格子淡去 → 业务自己贴封条的货 ②货架上贴封条的货 +「已预留」+ 买家被挡（禁止符）③**对讲机调度员出场喊确认 / 取消** → 成了：撕封条、货出库；没成：撕封条、货留架上「照常卖」④「预留 / 确认 / 取消」三色标签 → 念 TCC 时「预留确认取消」
8. **tcccost** 锁住的格子一闪即灭（锁的时间短）→ 三张色单（三套动作）→ 重复条子打叉（防重复）
9. **saga** ①红站蓝站各自盖章，蓝站货真出库（货架留空格），红站记订单 ②红站账本红叉 → 货沿原路重新上架（反向动作）③打叉的倒拨钟（不是时光倒流）+ 出过库的货 + 补满的货架 → 念 Saga 时「补偿事务」
10. **sagacost** 锁格子打叉（不锁货）→ 眼睛看着空格货架（别人看得见）→ 红叉账本 + 重试箭头（补偿也可能失败）
11. **message** ①调度员淡去（连调度员都不要）②红站账本 + 条子 → 跑腿员跑到蓝站 → 签收单 ③单号条码 + 重复条子打叉；橡皮单打叉（不撤回）、重试回补打叉（不补偿）→ 可靠消息
12. **eventual** 账本已记、货架还满（黄灯）→ 中间那箱货被搬走，留下空格 + 绿勾，最终一致
13. **recap** 天平：左调度员 + 沙漏（稳但慢）；右封条货（先预留）、单箱货（先做后补）、跑腿员（保证送到）+ 黄灯（短暂对不上），分布式事务
