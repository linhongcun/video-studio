## 各章画面
1. **hook** ①第 0 帧封面大字「两个库」/「怎么一起成功或一起失败？」→ 手机成功页 + 硬币 → 货架满着 + 红叉账本 ②两个数据库：一个绿勾、一个红叉 + 火花
2. **signal** ①两个库 + 问号 + 绿牌 ②库变红站（账本）、蓝站（货架）——驿站只在此后出现
3. **local** ①单库：整页擦掉 → 分成红站蓝站，红站擦自己的，蓝站货架打红叉 ②中间问号：得有人统一指挥
4. **prepare** ①对讲机调度员出场 ②问号 → 红站铅笔单（不盖章）→ 蓝站货进待出库格子锁住
5. **commit** ①绿牌 → 印章盖章；红牌 → 橡皮全部擦掉 ②铅笔单 → 盖章单，两阶段提交
6. **stuck** 对讲机红叉，铅笔单和锁着的货不动，沙漏干等（push-in）
7. **message** ①调度员淡去 ②红站账本 + 条子 → 跑腿员跑到蓝站 → 签收单 ③单号条码 + 重复条子打叉，可靠消息
8. **eventual** 账本已记、货架还满（黄灯）→ 货架少一箱 + 绿勾，最终一致
9. **recap** 天平：左调度员 + 沙漏（稳但慢），右跑腿员 + 黄灯（快但短暂对不上），分布式事务
