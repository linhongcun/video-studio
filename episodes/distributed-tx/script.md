# EP.21《下单成功了，库存怎么没扣？》

2026-10-24，按用户整批旧视频重制目标制作，对应#73。仅一条可靠消息主线，不并列其他方案。公开官方资料与适用边界见research.md。

- 新术语仅分布式事务、最终一致；首次命名在03与12独立句首，按共享声学起音规则挂词。消息队列、幂等沿用前期，不再展开定义。
- 同一示例订单8124、通知E8124、库存4→3；数字均示例。订单库与库存库不同，订单行和待发送记录在同一订单库本地事务；消费端库存修改与已处理标记也在同一库存库本地事务。
- 订单“已记录”不等于完整业务成交；本例库存足够、服务恢复后展示成功收敛，永久失败及缺货需处理。去重只针对本次通知，不能用一个泛化订单标志吞掉后续合法业务。
- 深色全屏canvas，不用驿站、物理锁、打印机等实物比喻，不造假应用窗，不常驻密集多表。一个焦点、一条移动的事件，步骤逐步揭示。
- 无ASR时如实保留句级边界与实测句首起音，不编造逐字识别。
