# 《什么是分布式事务？》（入门前置片）

2026-10-24，按用户要求新增前置视频；现有EP.21保留为方案详解。本期先认识问题和边界，不重复五方案总览。

- 一条主线：订单8124购买商品7042一件，库存4→3；全部数字为教学示例。订单“已记录”不等于整笔业务成功；按示例业务规则，确认订单须已有本单库存安排。
- 20镜、40句；5章conflict/local/split/uncertain/recap。时长由实际配音决定，不强行加速。
- 三个术语：本地事务04、分布式事务10、最终一致18，均首次放句首。不得在此前章节导航中提前上屏；首帧用问题标题“一笔订单，两个结果？”。
- 深色全屏canvas，不造浏览器或应用壳，不用比喻。按动作逐步揭示，非当前内容缩退，主体状态不能只靠字幕推进。
- 同库示例仅为受同一本地事务管理的事务型数据，不泛化为“同库一定共同提交”；独立事务也可以存在同库。分布式事务不以机器/服务数量定义，也不必然提供所有方案通用的全局原子性和隔离。
- “同步协调”“异步推进”只是引出不同保证的思路，不展开协议；各自保证、资源前提与失败处理进入现有[方案详解](../../episodes/distributed-tx/article.mdx)。
- 技术核验与来源见research.md；起音、动态实现和成片检查尚须由制作流程实际完成。

### 09 partial-success

### 14 unsafe-retry

frame：canvas
章节：最棘手的是结果未知

### 16 safe-retry
