# 《Saga：扣款成功，缺货了怎么办？》

2026-10-24（北京时间）。按用户最新反馈拆成独立短片；14镜28句，只讲本地步骤先提交及失败后业务补偿。实际时长由自然配音决定，目标约90–150秒，不加速。

- 教学示例：订单8124购买商品7042一件，金额200元；成功分支账户1000、库存4，失败分支明确重置账户1000、库存0。
- 主体动作承担解释：1000→800、库存4→3、失败后新增退款+200→1000，原扣款-200始终保留。退款失败另起分支，保持800与待恢复状态。
- 首次标签Saga在03句首、补偿在09句首；此前白话导航不提前显示术语。相关本地事务概念由前置片建立，不重新铺方案表。
- 深色canvas，无比喻、实物和假应用窗口；标明示例数据。不同分支明确重置。
- 补偿不是数据库原事务回滚；不承诺Saga全局隔离、补偿必成或无限重试必成功。临时故障与业务拒绝分清。
- 当前技术核验见research.md；独立教学审定后再配音。
