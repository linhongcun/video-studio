## 各章画面
1. **hook** ①第 0 帧封面大字「两个订单」/「怎么撞成同一个号了？」→ 自己的订单页（头像剪影 + 色块条码），客服出现，「别人的订单」时陌生人订单条（红框、橙头像）滑进来 ②拉远：好几个通用数据库各自盖出一样的条码 → 火花撞号
2. **signal** ①两个库 + 「怎么撞」「怎么防」气泡 ②「把每个库想成一个驿站」时库变成红站蓝站 → 条码打印机 → 小本子（驿站只在此后出现）
3. **clash** 红站蓝站互不知道 → 各打出一模一样的条码 → 火花
4. **autoinc** ①本机服务器 + 小本子 +「本机」②自增标签：只管自己这台
5. **need** 所有站 + 总台发号机变亮，人往发号机挤（不能挤回去）
6. **snowflake** ①打印机旁依次亮出色带 / 徽章 / 流水戳 ②两站打出不同条码（绿勾）③雪花算法标签
7. **clock** 墙钟被拨回（红弧，无刻度）→ 黄灯停打，条码变暗；时钟回拨标签
8. **counter** 中央一台发号机 + 公共计数器小标签，人群又都挤回这台发号机（不再用窗口）
9. **recap** 拆开的数据库 + 红蓝不同条码 + 绿勾 → 全局唯一 ID
