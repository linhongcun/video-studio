# EP.20 pronunciation.md

送 TTS 的文本里多音字换同音字；稿子和字幕保持原字。核对：单字切出识别 + 与同音参照比频谱（同 EP.17/18/19）。按 research.md §7 多音字表执行。配音：冰糖。

## 「重」必须分清（chóng / zhòng）

| 词 | 读音 | 位置 / 说明 |
|---|---|---|
| 重复 / 不重复 / 打重复条码 | **chóng** | 第 4、7 章；不能读 zhòng |
| 重新（重新挤回） | **chóng** | 第 5 章；不能读 zhòng |
| 重要（本稿旁白未用） | **zhòng** | 若改稿加入读 zhòng，不能读 chóng |

## 「行」（若出现）

| 词 | 读音 | 位置 / 说明 |
|---|---|---|
| 一行 / 行（表的一行） | **háng** | 本稿旁白未用「行」；文章若念到「新行」读 háng，不能读 xíng |
| 银行 / 行列（若对比） | 按语境 | 旁白未用 |
