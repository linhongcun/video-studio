# P06 · 12个球称三次读音

| 文本 | 读法与注意点 | 出现镜号 |
|---|---|---|
| 称／称重／三称 | chēng / chēng zhòng / sān chēng；动作“称”不读chèn，次数不与重量混读 | 01—15 |
| 等臂天平 | děng bì tiān píng；左右数量相同的等臂比较，不读成等重天平 | 01 |
| 偏轻／偏重 | piān qīng / piān zhòng；每个结论都保留轻重，不能吞掉“轻”或“重” | 01—15 |
| 左重／右重／平衡 | zuǒ zhòng / yòu zhòng / píng héng；表示比较结果，不表示直接认定哪一号异常 | 02—15 |
| 二十四种／九种／八种／三种／两种 | 分别读出候选数量；“种”指编号加轻重的可能状态，不是球的个数 | 02—10、12 |
| 一、二、五号，对三、六、九号 | 依次读yī、èr、wǔ hào，duì sān、liù、jiǔ hào；左右分组之间自然停顿，不能听成连续编号范围 | 07 |
| 一号对二号 | yī hào duì èr hào；一号始终左组，二号始终右组 | 08、11 |
| 三号对九号 | sān hào duì jiǔ hào；三号左、九号右，九号已知正常 | 09 |
| 七号对八号 | qī hào duì bā hào；七号左、八号右，轻重解释随已有候选改变 | 10 |
| 九、十、十一号 | jiǔ、shí、shí yī hào；是三个独立编号，不是九到十一种状态 | 12、14 |
| 十二号对正常的一号 | shí èr hào duì zhèng cháng de yī hào；不要把“十二号”读成“一、二号” | 13 |
| 九号对十号 | jiǔ hào duì shí hào；九号左、十号右，偏轻时结果方向要清楚 | 14 |
| 轻重互换／左重右重互换 | qīng zhòng hù huàn / zuǒ zhòng yòu zhòng hù huàn；两类变换均须读出，球号不换 | 11 |

每镜严格两句。07的三球对三球、08主例第三称、11的镜像结果顺序、14同球号不同轻重的结果应分别核对，不能靠朗读加速省略编号或结果。句级起音、声学边界、语义听辨和逐字ASR分别记录，尚未执行的项目不得记为通过。
