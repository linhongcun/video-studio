# P10 · 100囚徒与一盏灯读音

| 文本 | 读法与注意点 | 出现镜号 |
|---|---|---|
| 囚徒 | qiú tú；题目人物，不替换成其他角色 | 01 |
| 一盏／亮／灭 | yì zhǎn / liàng / miè；灯态变化需区分清楚 | 01、03—14 |
| 计数员／计数 | jì shù yuán / jì shù；“数”读shù，不读shǔ | 03、05—14 |
| 发信／发送／发过 | fā xìn / fā sòng / fā guò；“发”读fā | 03—14 |
| 成功发出一次 | chéng gōng fā chū yí cì；强调成功开灯才消耗资格，不是第一次来访就用掉 | 03—04 |
| 九十九／第一百份 | jiǔ shí jiǔ / dì yì bǎi fèn；目标是其余99人，不将计数员多算一份 | 03、12、14 |
| 零号／一号／二号／三号 | líng hào / yī hào / èr hào / sān hào；固定同号，零号是唯一计数员 | 05—11 |
| 从零加到一／两份／三 | cóng líng jiā dào yī / liǎng fèn / sān；接收后才加，不按来访次数加 | 07、09、11 |
| 灯灭时／灯亮着 | dēng miè shí / dēng liàng zhe；“着”读轻声zhe | 04、08、10、13 |
| 资格保留／重复增加 | zī gé bǎo liú / chóng fù zēng jiā；“重”读chóng | 04、07 |
| 公平／最终／多少天 | gōng píng / zuì zhōng / duō shǎo tiān；公平保证最终，不承诺固定天数 | 13 |

每镜严格两句。06和08的未发送者遇亮仍保留资格，07的一号见灭不重发，09的计数员见灭不加，以及11接收第三份后才确认，应分别核对。句级起音、声学边界、语义听辨和逐字ASR分别记录；尚未执行的项目不记为通过。
