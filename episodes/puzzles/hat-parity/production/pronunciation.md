# P08 · 配音读法

配音及字幕以本期 `script.md` 的14镜28句中文数字全文为准。使用冰糖、正常语速；不通过加速压进估算时长。实际音轨、起音、听辨和逐字ASR的执行结果应由本期生产记录给出，本文不是已通过记录。

| 文本 | 读法与检查点 | 镜号 |
|---|---|---|
| 一号／二号／三号／四号／五号 | yī hào / èr hào / sān hào / sì hào / wǔ hào；编号固定，不换成第一位、最后一位等可能随视角变化的称呼 | 02—14 |
| 队尾 | duì wěi；1号在左侧队尾，最先回答；不是队首 | 02 |
| 黑／白 | hēi / bái；1号的词编码奇偶，从2号起是本人推定的真实帽色 | 02—14 |
| 奇数／奇偶 | jī shù / jī ǒu；奇读jī，不读qí | 04—14 |
| 偶数 | ǒu shù；两顶、零顶是偶数，三顶、一顶是奇数 | 04、06、07、08、09、10 |
| 说黑代表奇，说白代表偶 | 本期固定映射，不得沿用原资料黑偶／白奇的相反编码 | 05 |
| 三顶／两顶／一顶／零顶 | sān dǐng / liǎng dǐng / yì dǐng / líng dǐng；数量指黑帽，不是所有帽子或人数 | 03—10 |
| 自己加前方 | 当前发言者和所有前方的人；与单独“看见前方”区别清楚 | 06 |
| 去掉 | qù diào；指从剩余黑帽计数中扣除已知帽色，不是让人物离开或拿掉真实帽子 | 07、09、10 |
| 零是偶数 | líng shì ǒu shù；不可漏掉零或读成奇数 | 10 |
| 裁判 | cái pàn；明确不需要裁判报告正确答案，后续人自行推理 | 11 |
| 翻转 | fān zhuǎn；黑帽使奇变偶或偶变奇，白帽不变 | 12 |
| 二号到一百号 | 共99人，包含两端；不要读成一号到一百号都保证正确 | 12 |
| 九十九人／一百人 | jiǔ shí jiǔ rén / yì bǎi rén；前者为保证人数，后者仅可能全对 | 01、13、14 |
| 同一句话 | 指1号在仅自身帽色不同的两个可能局面中，因观察相同而给出的相同颜色词 | 13 |

重点逐句核对05的固定编码、07奇变偶、09白帽保持偶、10黑帽使偶变奇及零为偶、11第一人只是本例错误、12的保证范围、14的至少99与可能100。句间停顿服务自然表达，不作为题内人物可利用的额外信号；画面也不得把配音时长或语调差异演成协议的一部分。
