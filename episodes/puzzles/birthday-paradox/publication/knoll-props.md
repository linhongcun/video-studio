# EP53 · 趣味推理P07 · 制作说明

本期唯一问题：365天均匀独立模型下，至少多少人使任意两人同生日概率超过一半。前置只需分数、百分比；正文逐人条件连乘与补事件，复杂配对推导留文章。

- 11镜22句，四章；真实正文3681帧／30fps＝122.7秒，资料列表默认另150帧。最终帧数以实际渲染回执为准。
- 声音：新冰糖TTS，保留22个选定take，整轨48kHz单声道；同一WAV实体放置于remotion/public/audio/voice.wav，从0帧播放。shared声学与句级检查不代表ASR或全片语义听辨。
- 画面：1920×1080，趣味推理紫色正文和封面；珊瑚为当前条件，青为已确认状态；固定人物身份与既有日期，从示例路径逐个揭示，不表现主动选空日期。无装饰进度条。
- 05–09持续说明此前均不同的条件；第23人之前22个不同日期，余343／365。10显示理论补集49.27%＋50.73%＝100%，11比较22人与23并区分过半与保证。
- 正文在122.7秒收束，然后无旁白5秒参考列表，只显两源原题与作者；不追加代码、证明或引流。
- 图文图位编码前确定：07镜稳定状态2100帧／70秒，10镜补集稳定状态3210帧／107秒。最终视频生成后从同一准确帧生成图片并实看。
- 默认入口render-final.sh→npm run render，先资料/冻结校验，再新正文、实际BT.709转换、共享混音和同色参考列表。不得发布out/body.mp4。
- 冻结前独立无字幕连续预演、三比例COPYFIT/安全区；冻结后不继续改输入。正式媒体检查、实际资料页与双视口播放器另留QA，GitHub站点仅在这些完成后交付。
