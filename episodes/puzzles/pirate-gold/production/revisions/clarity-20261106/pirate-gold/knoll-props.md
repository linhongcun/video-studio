# EP54 · 趣味推理P09 · 制作说明

本期唯一问题：按明确投票规则，1号怎样让提案通过并留下最多金币。前置只需整数比较与至少半数；通过门槛、同钱反对、无未来承诺都先交代，逆向归纳名称不代替实际推导。

- 14镜28句、四章；实测正文4801帧／30fps＝160.033秒，默认再追加150帧资料列表。最终媒体帧数以实际渲染回执为准。
- 新冰糖TTS、48kHz单声道，选定takes与新整轨本期保存。实体public/audio/voice.wav从0帧播放；句级声学与PCM检查不等于逐字ASR或全片语义听辨。
- 画布1920×1080、30fps，沿趣味推理紫色/字体/P标识。固定1至5号身份，珊瑚突出当前提案、青色确认结果；题目海盗、整枚金币、选票直接参与过程，无装饰进度条或应用壳。
- 2→3→4→5是从后向前的假设推算，始终标记，不画实际淘汰后复活。主模型通过门槛依次1、2、2、3票，提案者只占一票。
- 所有投票前金额均为拟分配；否决后金额是后续比较基准。11镜的4号一枚仅是撤回的比较候选，不能记作已经支付。12—13镜拟给3、5各一枚来自共同待分100枚，计票达到3票后才确认实得。
- 从4/5号100/0，推出3/4/5号99/0/1，再得2/3/4/5号99/0/1/0，最后五人98/0/1/0/1。5人局2、4号反对，1、3、5号赞成；严格多数变体不进入视频。
- 先独立检查真实无字幕连续过程与COPYFIT，再冻结现行音轨、时序、图文图位、动画及完整输入闭包，正式编码后另检查成片。
- 默认入口render-final.sh→npm run render，先资料/冻结校验，再本期正文、实际BT.709像素转换、共享混音和同色5秒原题/机构资料列表。不得将out/body.mp4作为最终交付。
- 编码前Figure图位确定为第09镜3000帧／100秒和第13镜4365帧／145.5秒；声音结束后且动画确认结果区间内。成片后按同一真实帧生成JPEG并目视。GitHub站点在成片与播放器/图文检查完成后交付，外平台本轮未授权。
