# LC200 岛屿数量：从整座归属到迭代 DFS

本期基线为 `7e0172a2a10ba855f07ff793275298c208a19fe0`。2026-10-25通过联网阅读工具实际读取中英文官方题面与Python官方资料；制作issue #82只用于任务身份，不作为题目或算法来源。访问记录见[research/source-access.json](research/source-access.json)。

## 题意与约束

输入是非空的 `m × n` 字符网格，`"1"` 表示陆地，`"0"` 表示水；`1 ≤ m,n ≤ 300`。只通过上下左右相邻的陆地连接成岛，斜角接触不连通，返回岛的座数，不是陆地格数。[S1][S2]

“网格四条边被水包围”指网格以外可视为水，不要求网格的边缘格全为0；官方例子第一行、第一列均可以包含陆地。[S1][S2]

本片主例采用官方示例2，原图始终保持：

```text
11000
11000
00100
00011
```

这20格中有7块陆地，但只有3座岛：左上4格为一座，中间1格为一座，右下2格为一座。`(1,1)` 与 `(2,2)`、`(2,2)` 与 `(3,3)` 仅斜角接触。这里坐标从0起；视频采用从1起的行列说明时，明确对应为代码下标各加1。

## 方法如何选出来

目标是数“整座岛”，所以不能每遇到一块陆地就加一。扫描到未归属的陆地，先把岛数加一，再沿四邻找全与它相连的陆地并登记归属；扫描以后再遇到这些格，就知道它们已经计入同一座岛。这一步从防止重复计数的需要推出，之后才命名深度优先搜索（DFS）。

用显式栈保存已经归属、尚待展开的陆地。Python列表的 `append()` 与无下标 `pop()` 分别在末端加入和取出元素，构成后进先出的栈。[S3] `seen` 用集合登记陆地坐标，集合提供去重和成员判断。[S4] 图上的“已归属”不等于“已展开完”，更不等于把陆地改成海。

程序对新发现的陆地先 `seen.add`，再入栈。这样同一个格即使同时邻接多块待处理陆地，也只会入栈一次。程序不写入 `grid`；地图地形与单独的归属标记分别表达。

Python解释器存在递归深度限制，限制值及提高限制的安全范围依平台而定。[S5] 本题最大有90000格，细长单岛可能使递归搜索链很深，因此完整程序采用显式栈，不依赖调高递归限制。不能把这一选择说成Python在任何平台都只能递归某个固定次数。

## 固定访问顺序与真实trace

完整程序为[solution.py](solution.py)，26行、最长67字符；[solution.json](solution.json)由程序逐行生成，供完整5秒静态卡使用，不另写一份显示算法。

方向循环固定为右、下、左、上。由于栈是后进先出，不能把方向循环顺序直接说成展开顺序。官方主例从 `(0,0)` 开始时，先登记并压入 `(0,1)`，再登记并压入 `(1,0)`；所以首岛的弹栈顺序为：

```text
(0,0) → (1,0) → (1,1) → (0,1)
```

处理 `(1,1)` 的上邻 `(0,1)` 时，后者已经在 `seen` 中，但仍留在栈里等待展开；此处跳过，避免重复入栈。新岛的起点按行扫描依次为 `(0,0)`、`(2,2)`、`(3,3)`。

唯一动画数据源为[research/demo-trace.json](research/demo-trace.json)，由[research/generate_demo_trace.py](research/generate_demo_trace.py)对同份实际 `solution.py` 只增加观察回调后执行产生，绑定程序SHA。它不是另一套算法生成的假过程；脚本与实际执行验证见其说明。制作方原样复制至 `remotion/src/lesson.json`，画面按事件状态取阶段，不自行重算一套访问顺序。

trace坐标从0起，栈数组从底到顶。`mark` 为登记归属之后、压栈之前；`pop` 为开始展开；`expanded` 才表示该格四个方向都已检查完。集合快照以行列排序只是展示顺序，不暗示Python集合有访问顺序。[S4]

## 正确性与复杂度边界

1. 从一块陆地出发，只加入四邻陆地，所以不会跨水或跨斜角加入别的岛；反过来，如果仍有同岛陆地未被登记，沿它到起点的一条四邻路径，必有第一条从已登记格通向未登记陆地的边，已登记格被展开时就会发现它。因此栈清空时恰好登记了整座岛。
2. 每次加一的起点都未归属，既有岛的全部陆地已经登记，所以它属于一座新岛；每座岛总有第一块被扫描到的陆地，因此不会漏岛。岛数与这些起点一一对应。
3. 登记在入栈之前，使每格陆地最多入栈、出栈一次，水格不入栈。外层检查每格一次，每块陆地只检查四邻；按常规集合操作的期望常数时间模型，时间为 `O(mn)`，额外空间为 `O(mn)`。保留原图并不是原地常数空间方案。

## 独立验证

[research/verify_algorithm.py](research/verify_algorithm.py)直接执行本片实际解法，用独立并查集oracle验证：只合并右侧、下侧相邻陆地，按不同根数量判断岛数，避免镜像DFS实现。2026-10-25实际完成全部65536个4×4网格、16组边界/压力和300组固定种子随机输入，共65852组，17.542302秒通过。每组均执行原程序及同源AST观察版，实际完整分组与oracle根形成双射，输入深快照不变；每块陆地恰好登记、入栈、出栈、展开一次。
