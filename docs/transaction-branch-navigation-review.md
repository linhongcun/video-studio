## 验收标准

1. **开头提供可复述的路径。** 前两秒保留标题、具体冲突和可识别主体；进入机制讲解前或开始处，给观众足够时间看懂本片主干、主要分叉及当前示例所在位置。导航不能先铺满边界表或靠读字幕才知道有几条路径。
2. **当前位置持续可追踪。** 全图、局部与角落定位图的节点名称、相对布局、颜色和当前路径对应；先突出当前节点及连接，再开始其机制动作。历史路径与未走路径降低强调，不用相同高亮暗示同时执行。
3. **换分支回到正确前提。** 先退回可识别的分叉及全局位置，说明另一个示例或回看阶段的起点，再进入新分支；不能把两个互斥结局接成前后步骤。原示例数值、业务身份和持久记录遵守其本来状态。
4. **未知、失败和重试语义分开。** 结果未知是参与方/调用方当前的信息状态；不能直接标成已失败。重复请求是同一业务操作的再次尝试，不增加一个新的业务结局。失败后恢复读取既有记录，不能重新选择与可靠原决定相反的结果。
5. **地图稀疏、文字可读。** 全图只保留主干、必要分叉及短白话标签；局部只展开当前小集合。首次新术语仍跟随实际语音cue，导航不提前泄漏“补偿”“幂等”等尚未讲到的技术标签。不得缩小文字来维持一张密集地图。
6. **缩放是可追踪的连续动作。** 实际查看变焦前、变焦中间和落点，以及从局部回图的过程；对象位置连续，不用瞬间替换截图冒充缩放。摄像机只在结构变化处运动，保留落点停留，不频繁穿越或旋转造成眩晕。
7. **机制主体仍完整可见。** 导航退出或停在清楚的小定位区域后，原请求移动、单件资源流转、数字变化、可靠记录/本地提交及失败收尾继续完整演示。地图、标题、字幕和水印不遮动作，变焦不能把关键保存点藏在过渡中。
8. **正式成片与受审输入闭合。** 各制作方停写后由主代理统一冻结、编码；独立编辑再看实际MP4每片约15–20个关键帧，核对完整SHA。预演图数、抽帧数和实际查看数分别记录，不以静帧合格代替动态理解，也不把编码保真当作教学评分。
