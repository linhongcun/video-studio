## 观察、假设与改法

| 证据层级 | 判断 | 本轮接入 |
| --- | --- | --- |
| 单周观察 | 问句标题样本播放较好；部分趣味推理留存较好 | 新片优先试问句；首2秒声画提出题目目标或反直觉冲突，保持题意与推导完整 |
| 单周观察 | 总播放不代表新作或开头留存良好；两扇门跨平台指标不同 | 成片记录实际首2秒与后续接续，分平台/作品/版本复盘，不把B站播放高等同留存好 |
| 未验证猜测 | 凌晨与短时连发可能影响冷启动 | 另已授权新作试每日1～2个分散时段，明确时段/间隔，下一轮比较 |
| 未验证猜测 | 工程内容的术语门槛可能影响观看 | 可试真实生活中的使用需求/故障，再接术语；不使用无关比喻，不削去实现原理 |
