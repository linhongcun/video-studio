## 实际改动

- 每篇首个主要章节之前都有读者可见的具体入口与解释方向，内容仍围绕原例子。DNS将根、顶级域、权威与返回答案串入同一查询章；算法保留从题意到排除依据或不变量的推导；推理文分清可行构造、最优性与程序核验。
- 图与引用移动到当前解释所需的位置，保留原属性、图像和时间；完整实现、源码分支、概率变体与有限运行记录按用途分层。新增自检只用于适合条件变化判断的文章，均有解析。
- 文章目录由实际可见H2/H3生成，三级标题按层次展示；手机可原生折叠，桌面展开，无JS仍可操作。脚注、图内和隐藏区标题不进入目录。视频章及时码沿原路径，文章独有标题不制造视频章。

- 文章内长词可换行，修正既有消费组参考列表在手机因长commit SHA导致的整页溢出。此样式不修改程序文本或视频。
