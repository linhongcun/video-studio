The first pass is preserved as `first-pass-result.json` and `first-pass.log`: the 236 matrix checks and all eight screenshots succeeded, while media seek assertions failed. Its real Range response was HTTP 206 with `Content-Range: bytes 0-99/9080624`; Chromium then reported the full 111.666667s DNS timeline seekable and reached 26.133333s on the existing 26.133333333333333s chapter. The successful matrix was reused, not rerun. No media or source response was patched.

All eight saved viewport PNGs were actually opened and inspected individually. They cover visible openings, desktop depth, mobile expanded directories, and a mobile summary in both themes across the set. `visual-review.json` records each actual visible scope and SHA-256. These are simulated viewport checks, not physical-phone tests. No screenshot or page content was edited.

One non-blocking observation was reported to the main agent: the egg-drop deep-section screenshot is correctly positioned at its heading, but the TOC active highlight retains the previous section because the heading is above the observer's 20%–35% viewport band. Link targets and the independent video behavior pass. No application files were changed by this QA task.
