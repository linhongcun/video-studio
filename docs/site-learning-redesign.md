# IT小村学习站改版

用户于2026-10-24认可审查结论并要求实施。本次版本v0.54.0，以`706f0b13cb1068d75eb99e61577e2ff0a006142c`为内容基线，只调整站点，不重制媒体或重发平台。

## 最终结构

- IT小村作为读者可见品牌，统一页眉、标题、分享信息、RSS、页脚和图标。
- 首页优先呈现系统原理、Agent开发、算法可视化、设计模式四个方向及学习起点，再展示最近发布。
- `/learn/`提供四个方向的受众、目标及学习目录；`/library/`提供完整内容和方向、系列、标签、排序筛选。
- 保留八个`/series/<id>/`，改为有顺序的课程目录；保留全部标签URL，标签索引改为紧凑分组。
- Agent、算法与设计模式独立，系统内部五个系列继续衔接。已发布29篇，另保留1篇历史合集；规划不冒充已发布内容。
- 课程页增加视频/图文/课程目录入口，手机折叠正文目录、笔记本侧栏目录、真实系列目录；一般相关推荐移至正文后。
- 深蓝、青绿、少量暖金统一视频品牌，保留柔和浅色阅读、三档外观偏好、无JavaScript导航与原生媒体控件。
- 编译时移除标题中的“只放文章：”编辑提示，不修改MDX原稿或既有章节锚点。
- `/?series=...`兼容到新的全部内容筛选页；旧quick/videos入口、归档页与历史期号继续可达。
