# 两期设计模式修订的站点交付

本批只改D01策略模式与D02观察者模式。接入保留原URL、标题、EP23/28、学习顺序1/2、首发v0.52.0/v0.58.0、发布日期、源码入口和平台记录；版本由发布任务在同步最新主干后选择。

1. 根任务确认两片实际媒体QA通过后，执行`python3 docs/pattern-flow-ui-java/site-integrate.py --approved`。旧观察者接入脚本会重设首发身份，本批不使用。
2. 执行`node docs/pattern-flow-ui-java/site-qa.cjs`：同一次最终站点构建与一次历史路径回归，两页各1440/390视口的所有章节实际跳转、短静音播放、全部字幕与时序、无溢出；卡区三点无活动字幕、实际解码后暂停并导出Java卡帧。正文Java小节使用`#java`，与视频卡区一起验证。
3. 实际打开最终截图复核后，记录准确的查看范围。必要的浏览器恢复可用`--reuse-build`，前提是构建输入与产物指纹均未变；不自动重跑已通过的检查。
4. Release之后的Pages工作流成功后，运行`python3 docs/pattern-flow-ui-java/verify-online.py`：两片完整canonical视频流SHA、海报、全部字幕、章节、Java图文入口/卡区、元数据历史与真实Release链接；不保存远端媒体，不加缓存查询。

制作输入仍归各期owner负责。本目录不替代内容、Java编译运行、动态或实际编码复核；本地播放器检查不声称全片听辨、ASR、学习实验或用户观看认可。
