# 调研模板

当前实际核验示例见 `episodes-codex/db-index/research.md`、`episodes-codex/db-lock/research.md` 及本轮各期 `research.md`。本文提到的 degradation 文首结构是历史范例；新稿使用现行制作目录，不依据已被替换的旧站点稿恢复流程。

公开来源才能进脚本和文章。内部材料（handoff、旧分镜、群消息、未入库的 backup）只帮助起草，写的时候标「仅参考内部材料，不可作引用」，并且不要出现在 `article.mdx` 的脚注里。

`episodes/degradation/article.mdx` 的脚注是现行写法：资料名、访问日期、可打开的 URL。`episodes/degradation/script.md` 文首用「文章提醒」把只进文章的事实和片中主线分开。

## 每条出处

```markdown
- 主张：（片子或文章里的哪一句）
- 作者或机构：（论文作者、标准组织或官方文档维护方）
- 原始题名：（实际文档标题，保留原语言、字词与标点）
- 题名证据：（原文位置及仓内证据路径，对应 titleEvidence.locator / evidence）
- 年份或版本：（发布日期、标准编号、产品版本；没有就写「未标」）
- 链接：（https://…）
- 访问日期：（YYYY-MM-DD，写北京时间）
- 页面上的日期：（文档自己标的 Last updated / RFC 日期；没有就写「页面未标」）
- 用在：（镜号，或「仅文章」）
- 原句：（需要摘录时填写连续的实际原文，保留原语言；对应 quotation.text）
- 原句位置与证据：（章节/段落/行号等定位及仓内证据路径，对应 quotation.locator / evidence；无短引则省略）
- 片尾：（是否入选；对应片尾编号或「仅文章拓展」）
- 核验范围：（本轮实际读到的原文、版本/替代关系；未重新访问则保留历史日期并说明）
```

优先使用原始论文、标准、官方技术文档和原始数据，并优先使用 2020 年以后的页面。更早的材料条目上写「仅参考」，不作为唯一主论证；基础标准仍须核对替代关系及当前适用性，并补充现行维护材料，不能仅因年代久远就判定其技术内容失效。

## 片尾参考资料

每期技术视频选约2–5项实际支撑核心内容的资料，记录到本期 `references.json` 等工具输入，与上述论点条目及文章来源保持对应。片尾显示作者或机构、文档原始题名、年份或版本及必要的原文短引；配套文章提供完整标题、可点击链接、访问日期与支持论点。原始链接和本轮核验的固定版本可分别保留，不把转述文章、搜索摘要或内部记录冒充原始出处。

新片采用 `presentation: original-title-quote`。清单保留 `schemaVersion`、`episode`、`heading`、`checkedAt` 和 `sources`；每项保留 `id`、`organization`、`title`、`titleEvidence: {locator, evidence}`、`version`、`url`、`supports`、`sections` 及 `verification`。`title` 必须是实际读取文档的原始题名，不能用自拟摘要、翻译或缩写代替；`titleEvidence` 指向可定位的原题证据。此模式禁止 `displayTitle`、`displaySupport`，`supports` 只用于内部论点对应，不上屏；较早资料的「仅参考」写入 `note`。不能仅手填 `verified` 代替实际阅读与证据。

短引可选。没有需要展示的原文时省略整个 `quotation` 字段，不以空对象或无关段落凑数；有短引时填写：

```json
{
  "quotation": {
    "text": "<从实际文档复制的连续原文，保留原语言>",
    "locator": "<章节、段落或行号等实际位置>",
    "evidence": "<仓内原文证据路径>"
  }
}
```

以上仅是字段说明，不能作为真实引用直接提交。短引须逐字与实读原文核对，画面标「原文摘录」并给出位置；可以选择较短的连续原文，但不能擅自拼接、改词、添加省略号或把概括/译文填成原文。若另附译文须标「译文」，文章引用区的概括和解释标「编者说明」，当前卡只展示原题与可选原文，不显示这些额外解释。

资料卡可无旁白，每页最多2项、默认5秒并提示暂停阅读。原题和短引分别检查排版；超限时采用更短的连续原文或调整排版，不自动截断或概括原题。正式成片核对实际显示、清晰度与字幕边界。不能只列「参考资料」标题、挂不支持本片论点的权威名称，或把未执行的访问写成已核验。资料清单、题名/短引证据和生成输入按本期实际流程冻结；存量补片尾保留原正文及其已有冻结记录，另记本轮追加证据。

## 不能当作来源

- 没有 URL 的数字、口口相传的经验值（如「单表两千万」）。这类句子只放文章，并写「不是官方数字」。
- 真实用户数据、真实订单、真实商家名称。示例用 RFC 2606 的 `.example`，价钱和地址在画面上带「示例」。
- 未公开的接口、后台截图、只能内网打开的文档。

## 和脚本的分工

片中只保留一条主线需要的事实。自动降级、实现开关、状态机名字这一类，degradation 放在 `script.md` 的「文章提醒」和 `article.mdx` 的「只放在文章里的补充」，不进旁白、字幕和可见画面。
