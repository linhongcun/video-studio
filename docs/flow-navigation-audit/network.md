DNS建议：客户端本地检查→解析器缓存→必要时展开解析器分别询问根/TLD/权威→缓存并返回；各服务器不画成彼此转发链。原片9.33/34.8/44.43/69.73/86.9/96.17秒是建图与回图锚点。

HTTPS建议：将身份核验与密钥协商放在同一握手容器，身份失败侧出口；受保护传输在接收端另设验证通过/拒绝。原片26.83秒建全局，48.77秒看核验失败，57.77秒先回成功前提再看握手，85.43秒定位接收拒绝，106.67秒回全局。不要把握手内部过程机械画成绝对串行。
