# 按需查看文章原文

原文卡始终展开会占用阅读篇幅。本轮将共同引用组件改为段落旁的轻量「原文」入口，读者需要核对时再展开原句、说明和出处。

## 范围与交互

开工工作区干净，fetch并从最新 `29dc6461eb4a7bbc2fcc4bd02ce2761727fc1df1` 建立 `codex/citation-popovers`。现有47篇共有67处引用：66处接在段落后，1处接在策略模式的h3后。默认将入口放在前一段末尾；标题后的例外保留原位置的紧凑入口，不自动将正文整句标成已由引文证实。

- 桌面悬停短暂延迟后预览，指针可移入面板继续阅读；点击固定展开，再次点击、关闭按钮、外部点击或Escape关闭。
- 手机点按查看；键盘可打开、访问出处链接和关闭，必要时返回入口。一次只打开一处，入口的展开状态与面板同步。
- 浮层在入口附近展开，根据视口翻转或限制高度，可滚动长内容；不推动正文，不遮出视口。亮暗主题共用站点变量。
- 原文和出处仍在服务端HTML中。现代浏览器无JavaScript时仍可通过原生Popover点击查看；不支持Popover的浏览器保留完整引用作为降级。

只调整共享组件与交互，不逐篇改文章和引用数据，既有视频、文章、来源及元数据保持。515项完整SHA基线见 [baseline.json](baseline.json)。后续新期继续使用相同 `SourceQuote`，自动获得本次交互，制作与发布检查同步更新。
